学习路径：从基础方法到持续强化学习

经典算法提供评价、控制与规划工具，深度方法使用可学习的神经表示，持续学习关注完整智能体在长期交互中的表现。三者可以同时成立。下面按教学先修关系组织，不把它们当成互斥问题类。

强化学习研究智能体通过与环境交互实现目标。总览先说明一般接口、Markov 假设和大世界中的资源限制。本页据此安排先修内容。各方法章解释推导、更新与实现；研究和实验栏目使用相同的章节索引。

  2. 02

    函数逼近

    Part II：半梯度、离策略、资格迹与策略梯度。

  3. 03

    深度 RL

    用神经网络学习表示。组织 replay、target network 和 actor–critic 更新。

    新增问题：训练过程如何保持稳定？

  4. 04

    持续学习问题

    结合所需工具，研究完整学习器怎样适应、保留能力并积累知识。

    可用表格或深度方法；无需先学完所有分支。

箭头表示一种补先修的顺序，不表示后一个问题包含或取代前一个。TD、策略改善、平均奖励、资格迹与模型 backup 都可以用于持续学习。离线、部分可观测、约束与多智能体等问题还构成并列维度，可按研究需要交叉组合。

选择起点

只认识状态、动作与奖励
用总览先看研究对象，再从经典 RL完成回报、MC/TD 和两状态控制练习。需要神经表示时继续补函数逼近；小型持续学习研究也可以从表格例子开始。
读过 Sutton 第一部分，会运行 DQN 或 PPO
先用经典册的控制与函数逼近自测定位缺口，再读现代 DRL。能运行代码不等于已经明确 target、梯度和采样分布。
能独立实现并调试深度 RL
从完整学习器的控制比较与CRL 协议开始。明确目标来自哪里、信息由谁提供，再选一个失败机制与对应实验；不必先读完全部深度拓展。

基础分册：表格方法、函数逼近与深度 RL

共 26 章，按教学先修关系组织。表格、函数逼近和深度网络是算法工具；持续学习是这些工具需要应对的一组长期交互问题，不是读完前面方法后才出现的另一种互斥任务。

先用领域总览确定问题，再补所需基础。每章包含设定、推导、时序、手算、代码和带答案练习；奖励设计交代目标来源，持续控制比较包含内部状态与学习规则的完整智能体。

分册 01

经典 RL：从交互到评价与控制

从可解析的有限问题学习评价、控制和规划，再研究函数逼近。有限平稳 MDP 是这里的教学起点，不是所有强化学习必须满足的世界假设；经典方法也包括平均奖励、资格迹与在线跟踪。始终分清目标、估计对象、数据来源和学习规则。

  1. 交互、状态与回报

    一次行动的好坏，为什么不能只由眼前的奖励判断？

  2. 已知模型：策略评价与动态规划

    若已知每个动作的后果，怎样把局部计算变成长期判断？

  3. 未知模型：Monte Carlo 与 TD 预测

    不知道转移概率时，一条经历能够教会价值函数什么？

  4. 从预测到控制：数据与策略共同变化

    学到价值以后，怎样让行动真的变好？

  5. 多步目标与时间信用分配

    延迟到来的反馈，怎样影响更早的预测和决策？

  6. 函数逼近、采样分布与稳定性条件

    不能为每个状态保存一行表格时，怎样共享经验？

  7. 学习与规划的接口

    得到一条经验后，除了直接更新价值，还能学习什么？

表格与共享参数是两种表示方式，不是两个互斥任务类别。状态很多时，可继续补函数逼近与深度方法；研究持续预测、平均奖励或单生命期控制时，也可以直接使用经典工具。以完整学习器为对象的持续控制章会重新明确目标与比较条件。

分册 02

现代 DRL：可学习表示与稳定控制

深度强化学习用神经网络表示价值、策略或模型。它与持续学习可以同时成立，也可以研究固定任务或离线数据。本册先解释 DQN、actor–critic、PPO 与连续控制的核心接口，再按部分可观测性、探索、分布、离线数据、模型、约束和多智能体等条件选择并列研究分支。

  1. 神经网络改变了哪些条件

    把表格换成网络，为什么不是只换一种存储方式？

  2. DQN：经验重放、目标网络与 Double target

    如何避免价值网络用迅速变化的自身预测反复训练自己？

  3. 策略梯度与 actor–critic

    不通过枚举最大 Q，能否直接改善动作分布？

  4. GAE 与 PPO：估计优势和限制批内策略变化

    怎样利用一批轨迹多次更新，而不忽略数据来自旧策略？

  5. 连续控制：TD3 与最大熵 SAC

    动作是连续向量时，怎样完成价值改善中的最大化？

  6. 世界模型与规划：预测误差怎样进入决策

    学会预测环境，为什么还不等于学会最优行动？

  7. 部分可观测性与循环状态

    当前图像一样，最优动作却不同，网络应当学什么？

不必先读完所有深度研究分支才研究 CRL。选定问题后，再确定神经表示是否必要、信息与数据权限是什么，以及学习状态怎样长期保留。持续学习评价的是这些模块共同组成的完整学习器，而不只评价训练结束时的一组网络权重。

分册 03

CRL：长期交互中的学习、适应与知识积累

持续强化学习研究受资源限制的完整智能体怎样在长期交互中适应环境、选择行动并积累知识。经典或深度方法都可以成为其部件。先区分运行时的智能体—世界闭环与外部设计者的奖励、初始化、调参和重置权限，再定义表现与可实现的比较者，最后选择机制。

  1. 完整学习器、目标与长期交互协议

    比较的是当前策略，还是包含内部状态与更新规则的完整智能体？

  2. 状态与预测知识的分工

    长期经验应当形成什么可供后续决策使用的知识？

  3. 信用分配与流式更新是两个问题

    反馈怎样传到过去，与每步允许做多少计算，有什么区别？

  4. 学习规则的适应与跨任务元学习

    什么时候需要学习“怎样学习”，而不仅是更新策略？

  5. 知识保留与可塑性

    一个学了很久的网络变差，是忘记了，还是学不进了？

  6. 从预测到子任务、技能、模型与规划

    长期经验怎样形成可重复使用的行为，而不只是一组新参数？

  7. 持续探索、学习进展与恢复

    长期智能体应该把有限经验花在哪些问题上？

  8. 从学习材料到可检验的研究实验

    什么样的实验能够支持“更适合持续学习”的结论？

完成这一册后，可按问题进入对应教材章，而不必一次读完全部方向。一个可执行的起点是：固定基础 agent 和预算，只改变一个长期学习条件，提出能被对照实验否定的机制假设。

每节怎样学习

先用问题判断本节要估计或优化什么。读解释与公式后，独立完成自测，再运行小实验核对数值。需要完整推导和算法分支时，继续读对应教材章；需要扩大实验时，再进入原论文和完整实现。
