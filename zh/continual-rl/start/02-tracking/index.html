    LESSON 02 / 08 · 35 分钟 + 实验

    第一条曲线：旧经验什么时候成了负担？

    如果过去一万次 A 都很好，今天 A 坏了怎么办？

    只需这些基础：样本平均与 ε-greedy

    读完应能：解释常数步长的跟踪能力与噪声代价，并运行一个实验。

    先把问题放进一个例子

    浏览器实验让两臂的奖励概率由 (0.8, 0.2) 交换为 (0.2, 0.8)。你可以改变步长、探索率和随机种子，重新计算两种估计器的真实采样曲线。请先预测结果再点运行。

    一条你认识的更新式

    Q ← Q + α(R − Q)。括号里是新证据与旧估计的差。α = 1/N 是样本平均；随着经验增加，一条新证据的权重越来越小。它很适合估计固定均值，却可能对后来变化反应迟钝。常数 α 不会随生命长度自动降到零。

    手算三步

    当前 Q = 0.8，α = 0.1，随后连续得到奖励 0。更新后依次为 0.72、0.648、0.5832。若已访问该动作一万次、采用 1/N，第一次仅降到约 0.79992。在这个标量估计器中，就能看到估计稳定性与跟踪速度的权衡。

    不要把探索漏掉

    即使 B 变好了，若永远不选 B 就观察不到它。ε-greedy 保留小概率探索；这不是只调步长能替代的。实验必须区分“没有采到新信息”和“采到了但更新得太慢”。最好记录动作频率、价值估计和回报，而不只记录平均奖励。

    指标要围绕变化

    看切换前回报、切换后短窗口损失、后期恢复和整段累计回报。一个方案可能恢复快却一直抖动。下面的小实验在指定时间切换两臂的奖励分布，用来比较步长与探索怎样影响跟踪；深度网络的可塑性留到下一课讨论。

    相关术语
    步长 α
    新观测对当前估计的影响大小。
    探索率 ε
    每一步以 ε 的概率随机选动作；随机分支也可能选到当前最优动作。
    随机种子 seed
    用于重现一次伪随机采样；一个 seed 是一次运行，不是一个新算法。

    推导选读 · 从样本平均推到“有记忆长度”的更新

    看清旧数据为什么拖慢跟踪，也理解大步长为何更吵。

    代入一个例子

    α=0.1 时偏差半衰期约为 6.58 次“选中该动作后的更新”；α=0.5 时为 1 次。更快适应，也对近期噪声更敏感。Q=0.8 连续遇到三次 0 奖励，α=0.1 时得到 0.72、0.648、0.5832。

    适用条件：方差式假设固定奖励分布和独立样本，不直接描述自适应选择动作后的整段控制回报。半衰期是更新次数，不保证 7 个环境步就能恢复。

    先确认理解，再做一个改动

    01 · 理解题

    已经选过 A 一万次，为什么一次坏奖励几乎改不动样本平均？

    给我一个提示

    把这次的步长 1/10001 与 0.1 比较。

    参考答案与检查点

    新观测只占约万分之一。Q=0.8、R=0 时，更新后约为 0.79992；固定步长 0.1 则变为 0.72。

    02 · 操作题

    固定 ε=0.1、seed=7，只把 α 从 0.02 改到 0.5。请同时看回报、选 B 比例与 Q 值。

    给我一个提示

    先预测哪种设置更快放弃 A；再区分“估值已改变”和“动作已经改变”。

    参考答案与检查点

    观察切换后的 Q 排序和选 B 比例是否更快反转。大步长也可能让 Q 值更波动；不同 seed 未必同样排序。应记录现象，不能只根据一条线给出一般性结论。

    再往研究多问一步

    让常数步长从 0.02 增到 0.5。为什么恢复速度可能更快，但后期回报未必更高？

    思路与结论边界

    更大的 α 更快遗忘旧估计，也放大近期奖励噪声；价值排序可能反复翻转。单个种子不能断言最优步长。用 Python 版跑多个种子，分别报告变化后早期和稳定后指标。
