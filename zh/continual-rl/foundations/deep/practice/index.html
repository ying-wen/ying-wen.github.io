    当前价值等于即时奖励加折扣后的后继价值；预测目标与最优控制目标不同。

    函数与梯度

    神经网络把参数和输入映射为输出。链式法则必须指明哪些量参与求导，哪些量作为固定目标。

    经验分布

    从问题到方法

    直接求解的难点

    控制目标规定希望得到的后果，却没有直接给出网络能计算的梯度。算法必须说明怎样用实际数据构造目标，以及哪条求导路径联系到要改进的预测或动作。

    本章的核心思路

    先从 Bellman 关系推到 DQN 的一次更新，再比较 PPO 与 SAC 改变了哪些数据、目标和梯度条件。

    1. 1

      从行为目标得到可学习的关系

      奖励回报规定控制问题；Bellman 关系连接当前动作与后继价值，再用真实转移形成样本目标。

    2. 2

      确认保存的是哪个后继与边界

      任务期限在状态内；rollout 截止不产生真正终止，重置后的首观测不是上一转移的后继。

    3. 3

      沿经验推到下一次参数更新

      分开环境步与优化步；推导固定标签的梯度，再对照目标副本、裁剪和优化器的实际次序。

    4. 4

      说明旧轨迹怎样用于新策略

      旧概率、旧价值与优势各有来源；比率校正当前动作，不自动把旧轨迹变成新策略轨迹。

    5. 5

      区分两种动作及其梯度

      旧转移用于 critic，当前策略另采样动作用于 actor；熵项改变了目标，actor 还需要沿动作经过 critic 求导。

    6. 6

      把推导对应到实现与记录

      教材训练脚本与独立算法旧结果各用自己的参数、批次和评价定义。

    结论与条件：实现核对验证已检查的更新和边界；当前损失改善不保证闭环收益改善或长期适应。

    确认保存的是哪个后继与边界

    任务期限在状态内；rollout 截止不产生真正终止，重置后的首观测不是上一转移的后继。

    内置任务有五个位置，动作是左或右，位置四为目标。到达目标奖励一，其余步骤奖励 −0.02。令位置为 ptp_tpt​、剩余步数为 ntn_tnt​，则本任务状态为 St=(pt,nt)S_t=(p_t,n_t)St​=(pt​,nt​)，观察用五维 one-hot 加 nt/12n_t/12nt​/12 完整编码它。十二步是任务期限：同在位置零，剩余四步可以连续向右到达目标，剩余一步只能得到 −0.02。省略剩余时间，会把不同价值的状态混成同一个输入。最短四步到达的未折扣回报是 −0.02−0.02−0.02+1=0.94-0.02-0.02-0.02+1=0.94−0.02−0.02−0.02+1=0.94；折扣0.99下为 −0.02(1+0.99+0.992)+0.993=0.910897-0.02(1+0.99+0.99^2)+0.99^3=0.910897−0.02(1+0.99+0.992)+0.993=0.910897。

    上面的循环用了 replay 和 target network，也能在 DQN 与 Double DQN 间切换。它们作用在不同位置。Replay 将一个已有转移再次提供给更新器；目标副本决定尾值何时接收新参数；Double DQN 决定用谁选择后继动作、用谁评价。只有先保持目标与预算一致，关闭一个机制后看到的差异才容易归因。

    循环中的机制它改变哪项依赖仍然留下的问题
    均匀replay抽样本批来自有限buffer，减少连续邻接经验在更新中的直接相关，并允许重复使用buffer覆盖和年龄决定拟合权重；同一buffer的各批仍共享数据，世界变化后旧转移可能失配
    冻结目标副本在线参数这一步的改变暂不进入目标网络尾值标签可能错误或过时；参数共享与离策略自举的困难仍在
    标签停止梯度本次求导只经过当前预测，不经过尾值没有使标签独立于历史数据，也没有使标签成为真实价值
    Double选择/评价在线网络选动作，延迟网络评价该动作两个网络相关且定期相等；没有普遍无偏或非线性收敛保证

    5 · 沿循环的接口选择下一项问题

    读通一次采样与更新后，再问哪个条件需要改变：当前观察缺信息，就研究记忆；实际交互昂贵，就研究学得模型怎样参与计算；只能使用既有数据，就研究覆盖与外推。下面三条深入阅读各保留自己的推导，读者可按这项缺口选取。

    机制新增加的信息必须维持的关系
    模型学习预测奖励、下一状态或潜在状态规划使用的模型应与任务目标和动作语义一致
    recurrent state历史顺序、初始 hidden state、边界网络状态重建与参数梯度截断分别定义
    offline RL固定数据集与行为覆盖不能依赖未授权的新环境交互纠正外推
    CRL持续时间线、变化机制、资源与 reset 权限学习期间的损失和适应成本不能只由最终冻结评估代替

    数据记录也包括观测归一化器与奖励变换的状态。若训练过程中更新归一化统计，旧 replay 的原始观测与已归一化特征会产生不同语义；必须选择保存哪一种，并保持实验一致。

    在分布式系统中，经验还可能等待多个参数版本。采样策略、推理参数和学习参数的延迟由 大规模训练 进一步展开。持续学习则同时评价当下收益、知识保持和以后还能否学会新目标；下表从具体失败选择干预。

    观察到的问题需要分开的解释最小区分实验
    变化后回报下降旧 replay 失配、critic 标签漂移、策略覆盖不足固定网络容量，对照新数据与混合数据，并记录关键动作覆盖
    训练越久越难学表示退化、优化器状态、目标尺度改变重置输出层、优化器或部分单元，分别测同一新目标的学习曲线
    长延迟奖励学不到历史状态不足、信用窗口太短、探索不到给充分状态、延长梯度窗口、提供探索轨迹，分别作 oracle 对照
    模型规划反而变差模型误差、规划分布偏离数据、计算预算变化真实模型与学习模型对照，并固定总计算预算

    每个对照只改变一个机制更容易解释，但 oracle 也需要标出信息权限。例如给真实隐状态可以定位表示瓶颈，却不能作为同等信息下的部署方法；允许重置环境的实验也不能直接声称解决不可重置单生命期控制。

    深入阅读可塑性证据怎样读：五类实验、三种秩与必要的对照

    比较可塑性研究的任务、测量与对照，作为进入持续学习的延伸阅读。

    “训练很久以后收益下降”是观测，不是机制诊断。新目标可能更难，数据可能变化，旧策略也可能访问不到有用区域。可塑性实验要问一个更窄的问题：在匹配的新目标、数据和学习预算下，已经训练过的学习器是否比合适的新初始化更难学习？训练误差、泛化误差和旧知识保持须分别观察。

    类增量 CIFAR-100：类别逐步增加，旧数据仍可训练在数据仍可获得时，旧网络与从头训练网络的差别类别变多本身会变难；准确率下降不单独证明遗忘
    Online Permuted MNIST：连续输入置换、逐样本更新长序列新映射上的适应，较少跨任务语义共享独立置换上的可塑性不等于有结构任务的快速迁移
    Slowly-Changing Regression：固定目标网络，输入的一部分缓慢翻转没有 TD 或控制闭环时，表示与优化怎样适应分布变化小网络监督结果不是深度 CRL 控制结果

    深入阅读5.1 · 保留旧知识与学会新知识是两个检验

    分别检验保留旧知识和学习新知识，避免把两种失败归为同一原因。

    遗忘检验问：训练新问题以后，旧问题的表现是否变差？可塑性检验问：给定相同的新问题与学习预算，当前学习器是否比适当对照更难学会？一个网络可以保留旧预测，却因步长极小而几乎学不会新目标；也可以快速学会新目标，却覆盖旧预测。

def update(q,target,opt,data):
    x,a,r,xp,d=data
    # 步骤 1：冻结 Bellman 目标。真正终止关闭所有尾价值。
    with torch.no_grad(): y=r+.99*(1-d)*target(xp).max(-1).values
    values=q(x); observed=values.gather(1,a.long()[:,None]).squeeze(-1)
    td=.5*(observed-y).square().mean()
    # 步骤 2：拉低整体动作值相对数据动作值，softmax 梯度精确可算。
    penalty=(values.logsumexp(-1)-observed).mean()
    loss=td+penalty
    opt.zero_grad(); loss.backward(); opt.step()
    polyak(q,target)
    return dict(td_loss=float(td.detach()),conservative_penalty=float(penalty.detach()))

    9 · 练习与答案

    • 问：旧replay转移被再用时，什么保持不变、什么重新计算？答：记录中的观察、实际动作、奖励、后继和终止标志不变；当前预测、后继选择及网络尾值按本次版本重算。
    • 问：已用no_grad生成标签，为何还要目标副本？答：no_grad决定这次不沿标签求导；副本延迟在线参数变化进入后续标签。两者控制不同时间上的依赖。
    • 问：PPO批次在episode中间结束，是否清零尾值？答：不清零；末行残差保留实际后继价值，GAE只停止跨入下一批。
    • 问：SAC更新actor时冻结critic，梯度如何经过critic？答：critic参数不写入，但保留输出对新动作的导数，继续沿动作生成器回到actor参数。
    • 练习：不运行训练，沿train_dqn复算1600环境步的写入与同步。答：从零索引t=32到1598的偶数索引共784次优化，目标网络按第100、200……1600条转移共同步16次。
    • 问：重建误差下降是否保证模型控制改善？答：不保证。Bellman 相关误差、规划覆盖和奖励敏感维度可能仍有偏差。
    • 问：detach hidden state 是否清除 agent 的记忆？答：不清除数值记忆，但截断其对早先参数计算的梯度依赖。
    • 问：CQL 正则能从零数据推断未见动作奖励吗？答：不能。它限制乐观外推，不产生缺失的因果信息。
    • 实验：把 DeadlineChain 的剩余时间从观察删除，在不同剩余步数的同一位置比较价值目标；答案是出现状态混叠，不能简单归因于 DQN 优化失败。
