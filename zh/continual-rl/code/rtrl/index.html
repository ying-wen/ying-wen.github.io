    1 · 实验要回答什么

    每步8个U(-1,1)输入组成独立序列；tanh老师a=0.8，b中点从0.4变-0.4。学生初始[0.3,0.1,0]，段内参数冻结、段间SGD；曲线为更新前误差平方EMA(0.95)，每段隐藏状态清零。

    任务
    recurrent_sequence_prediction
    指标
    更新前序列预测平方误差 EMA（越小越好）
    预算时钟
    sequences。每步一段长度8序列；中点老师输入权重反转；段内参数冻结、段间更新；元素预算=8*steps。
    对照
    截断 BPTT，相同任务、预算与种子列表。

    小型教学任务，非论文基准复现；不声称持续学习算法的一般有效性。

    2 · 运行、观察、定位

    先下载完整代码包。单个文件展示算法核心，运行仍需要包中的环境与记录工具。深度算法另需 PyTorch。

    完整代码包仅此算法文件GitHub 仓库
    python3 implementations/continual/rtrl.py --steps 1200 --seeds 0 1 2 3 4 --out results/MY_NEW_RUN
    1. 准备：选择训练种子，初始化参数与环境。查看源码中的 run。
    2. 采样与目标：区分交互样本、固定数据与已知模型备份。有 bootstrap 的目标在真实终止处关闭延续项；外部预算截止不自动等于终止。
    3. 更新：查看 update 或标注的更新段。检查哪些参数读取旧值，哪些量停止梯度。
    4. 记录：终端显示算法、seed、phase、当前预算与指标。CSV 还保留 loss、TD error 或模型备份等算法特定诊断。
    5. 对照：打开输出目录的 index.html。每个点可回查相应 seed 的 metrics.csv 和 events.jsonl。

    这张曲线的 value 与 step
    value：评价什么
    每段含8个独立均匀输入。教师递归网络从零状态生成末端标签；学生也从零状态展开，先计算末端预测误差，再更新一次参数。value 是这些更新前误差平方的指数平均，不是更新后的误差或独立测试集误差。
    step：怎样计时
    step 是已经处理的序列数，element_steps=8×step。段内参数固定，段间学习；两种方法都前向处理全部8个输入。RTRL传播完整参数敏感度；TBPTT只反传最后3个位置，保留第5个位置的活动数值。这里没有环境行动、经验回放或跨段保留的活动。
    怎样汇总
    第一段的 EMA 等于该段误差平方；以后按0.95×旧EMA+0.05×新误差平方更新。教师输入权重在总序列预算中点从0.4变为−0.4；变化时不清空EMA，曲线包含先前误差的残留权重。取该记录时刻的值；不先对曲线上的时间点求平均。 先在每个完整运行内计算 value，再在同一 step 上跨运行种子求均值和样本标准差（分母 n−1）。时间点不是独立重复；确定性计算即使换用种子也可能完全相同。标准差带不是置信区间，也不是单次观测的取值范围；图中的带可能越过奖励或误差的可行边界。
    从记录能重算什么
    CSV可重算检查点上的跨运行均值、样本标准差，并由element_steps核对输入预算。只保存每15段的EMA和更新后递归权重，未保存逐段输入、预测、标签和全部参数；不能由EMA恢复各段误差、完整梯度或持续控制收益。

def gradient(theta,inputs,target):
    # 单段期间theta固定，因此递推是精确参数Jacobian。
    a,b,c=theta
    state,jac=0.,[0.,0.,0.]
    for x in inputs:
        previous=state
        state=math.tanh(a*previous+b*x+c)
        local=[previous,x,1.]
        jac=[(1-state*state)*(a*old+direct) for old,direct in zip(jac,local)]
    error=state-target
    return [error*j for j in jac],error

def update(theta,inputs,target,alpha=.05):
    grad,error=gradient(theta,inputs,target)
    return [w-alpha*g for w,g in zip(theta,grad)],error

def run(seed=0,steps=1000,emit=None):
    check_steps(steps)
    rng,rows,theta=random.Random(seed),[],[.3,.1,0.]
    error_ema=0.
    for t in range(1,steps+1):
        xs,target=recurrent_sequence(rng,t,steps)
        theta,error=update(theta,xs,target)
        error_ema=error*error if t==1 else .95*error_ema+.05*error*error
        log(rows,t,error_ema,steps,emit,recurrent_weight=theta[0],element_steps=8*t)
    return rows
