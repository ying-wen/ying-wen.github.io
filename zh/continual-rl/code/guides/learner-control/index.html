    持续控制：共同检查点后的学习与冻结

    这里比较两个真实交互程序。它们前 400 步完全相同。之后，一个继续更新参数，另一个冻结参数。两者都保留记忆、随机数状态和已经走到的位置。第 600 个原始步开始，正确路线从左改为右。这个变化时刻不随运行预算改变，也不作为提示输入给智能体。

    1. 问题和时间单位

    智能体没有独立回合。大厅、行进和失败恢复属于同一条生命轨迹。

    当前阶段可用动作后果
    大厅探测花 1 步，奖励 −0.05，获得当前正确路线线索。
    大厅左或右路线花 1 步，奖励 −0.02，进入所选走廊。
    行进等待第一个等待步奖励 −0.02；第二个等待步到达。
    正确到达无额外动作这次到达奖励 +1，下一状态为大厅。
    错误到达无额外动作这次到达奖励 −0.4，进入四步恢复。
    恢复等待每步奖励 −0.05；四步后真实返回大厅。

    成功按到达时的路况判断。一次成功行程用 3 个原始步，奖励总和为 0.96。一次失败及完整恢复用 7 步，奖励总和为 −0.64。探测与恢复不是免费的外部操作。

    观测包含阶段、剩余行进或恢复时间、已经选择的路线。探测之外不直接显示正确路线。记忆保留最近一次探测线索，直到新的探测覆盖它。环境改变后，旧线索可能过时。

    2. 两个独立入口

    • online_differential_q.py：一直进行差分 Q 和奖励率更新。
    • frozen_parameters.py：前 400 步调用相同学习更新，此后只禁止 Q 和率的写入。
    • _common.py：共同环境、合法动作、线索记忆和真实交互计步。

    初始化为 27 个合法“阶段/时钟/已选路线 × 记忆线索”行的零 Q，奖励率为零，记忆为空。大厅初始行动分布相同且均匀。行为采用 ε=0.15 的 ε-greedy；行进与恢复只有等待动作。

    令 z 为可观测阶段和记忆共同构成的智能体状态。每一步使用更新前的 Q 和率计算：

    δt=Rt+1−g^t+max⁡aQt(zt+1,a)−Qt(zt,At).\delta_t=R_{t+1}-\widehat g_t+\max_a Q_t(z_{t+1},a)-Q_t(z_t,A_t).δt​=Rt+1​−g​t​+amax​Qt​(zt+1​,a)−Qt​(zt​,At​).

    随后令当前状态动作的 Q 增加 0.1δ，率增加 0.005δ。两个更新使用同一个旧参数误差。没有任务终止掩码；打印日志和结束预算不产生虚假的终止转移。

    冻结只作用于参数。探测后的记忆写入、真实行进、恢复和行动随机数都继续。即使参数不变，记忆改变仍可能改变行动分布。把记忆也冻结，是另一个消融。

    3. 运行与检查

    从仓库根目录运行；输出必须使用一个尚不存在的新目录：

    python3 -m unittest discover -s tests -p 'test_learner_control.py' -v
python3 -m implementations.learner_control.online_differential_q \
  --steps 1200 --seeds 0 1 2 3 4 \
  --out results/learner-control-checkpoint-v1

    入口会运行在线方法和配对冻结对照。每个 seed 保存配置、原始事件、指标和源码快照。图为种子均值与一个样本标准差，不是置信区间。

    应检查：

    1. 前 400 步的完整日志、Q、率、记忆和 RNG 相同。
    2. 冻结后 Q 与率完全不变，但记忆仍可写入。
    3. 将未来变化从 600 改为 900，不影响前 400 步。
    4. 620 步运行与 1200 步运行的前缀完全相同。
    5. 每个探测和恢复步都计入实际奖励与时间。
    6. 剩余行程在预算末被保留为未完成，而不是人工完成。

    4. 如何读图

    主指标是完整生命期的实际累计奖励除以已经发生的原始步数。它既不是率参数的估计，也不是冻结策略在一个新环境中的分数。另记录最近 100 步的奖励率、恢复耗时、失败次数、参数更新和记忆写入。

    五个 seed 的 1200 步教学运行中，400 步检查点两方法奖励率同为约 0.23686。在线方法在变化后下降，再恢复到约 0.22632；冻结对照最后约 0.12787。末尾 100 步的奖励率分别约 0.27234 和 0.02152。比较时应保留变化后的暂态代价，而不是只展示恢复后的窗口。

    这些数值只描述这个小任务和给定步长。它们不证明一般 CRL 优越性。这里不估计偏离遗憾，不提供外部重置，不含不可逆状态。固定记忆特征在变化后可能不满足静止 MDP 条件，因此不能直接套用平稳表格差分 Q 的收敛结论。

    进一步可研究：从不同训练年龄冻结、单独冻结记忆、改变探测成本、引入不可逆后果，以及匹配总计算的学习规则对照。每次只改变已声明的因素。
