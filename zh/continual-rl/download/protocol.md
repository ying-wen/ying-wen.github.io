# 强化学习实验与算法测试协议

## 1. 问题与估计对象

- 可证伪假设；预期改善的量与最小有意义差异：
- 至少两种竞争解释；能区分它们的干预：
- 固定策略性能 / 持续更新学习器 / 完整自动选择流程：
- 任务总体、独立随机单位与主比较：

## 2. 设定与信息权限

- 环境、版本、观测、动作、奖励和时间单位：
- episodic / continuing；terminated 与 truncated 的具体语义：
- 隐藏变化机制；任务 ID、边界、未来日程对谁可见：
- reset、replay、预训练、旧任务回访权限：
- 模块输入、持久状态、输出、更新顺序和因果时间：

## 3. 从公式到实现

- 目标函数、理想更新、可采样估计、近似与偏差：
- 同步旧参数或顺序写入；stop-gradient 的位置：
- 精确单元测试：手算 / 解析解 / 有限差分 / 独立 oracle：
- 终止 mask、GAE mask、off-policy 支持、option 时钟等边界：
- checkpoint：模型、优化器、目标网络、replay、归一化、RNG、状态、迹、元状态、环境：
- 完整训练与恢复训练的一致性测试；容差和非确定性来源：

## 4. 对照与资源

- 作者完整 baseline / 同骨干机制对照 / 消融，各回答什么：
- 无机制、随机或错位信号、匹配容量与简单方法：
- 真实交互、梯度步、规划调用、墙钟、参数与持久内存：
- 名义步长和实际更新范数、相对范数、KL：
- 候选与对手的搜索空间、搜索预算、早停和选择规则：

## 5. 开发、选择与确认

- 开发任务 / 运行 / 情景；允许修改的内容：
- 配置、代码 commit、依赖、协议与选择规则的锁定时点：
- 未用于设计的新训练种子 / 任务 / 完整生命期：
- 样本量依据；固定停止规则或合法序贯规则：
- 测试失败后修改方法意味着新的开发轮次，不重复声称独立确认：

## 6. 指标与统计

- 主指标、方向、窗口、任务权重和归一化锚点：
- 配对依据；外生情景 RNG 与动作 RNG 如何分离：
- 重采样单位；独立训练数；差值区间与失败率：
- 变化后恢复阈值、计时、持续确认和删失规则：
- 崩溃、资源超限、基础设施故障与未完成如何计入：
- 多重比较、辅助指标、探索性结论和等效界：

## 7. 持续学习与模块诊断

- A→B、A→B→A、全新 C；顺序、变化幅度与任务年龄：
- 在线主生命期与冻结副本分离；诊断反馈不得回写主运行：
- 新任务学习能力、旧知识保持、完整生命期收益：
- GVF：预测误差与下游控制收益分别报告：
- options：发现成本、原始环境步、终止与技能利用率：
- 模型/规划：准确模型、学得模型、无规划和固定计算对照：
- MARL：CTDE 权限、独立训练团队、伙伴变化与 cross-play：

## 8. 可复现交付与结论

- 完整命令、配置、机器与软件环境；原始逐运行记录：
- 预定全体运行列表；失败日志与任何重跑理由：
- 主结论、支持的机制、未排除的解释与适用范围：
- 负结果、资源代价与下一次可证伪预测：
