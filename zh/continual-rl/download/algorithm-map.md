# 教材与算法谱系

谱系按正文部分组织。箭头标明问题推广、估计变化或机制组合。

## I · 强化学习问题与目标

### [交互、奖励与优化目标](https://yingwen.io/zh/continual-rl/foundations/objectives/)

学习对象：奖励信号与跨时间的评价准则。

- 奖励 → 回报（定义目标）：规定累计时域、折扣和终止条件。改变这些条件可能改变策略排序。
- 策略目标 → 学习器的在线表现（改变评价对象）：冻结策略的价值不包含此前学习所付出的探索成本。

思考：奖励、回报、价值和学习器表现分别是什么量？

### [奖励假设与奖励设计](https://yingwen.io/zh/continual-rl/foundations/reward-design/)

学习对象：偏好、奖励表示与学习信号。

- 结果偏好 → 期望效用与逐步奖励（检查表示条件）：彩票偏好与时间一致性决定哪些奖励分解成立。Markov 性依赖状态信息。
- 给定目标 → 势函数塑形 / 奖励自动机（改变学习信号或记忆结构）：塑形需处理边界；自动机把部分历史要求放进状态。
- 人的反馈 → 偏好学习 / IRL / CIRL（推断目标信息）：奖励模型仍有假设、不确定性与分布外失效。

思考：当前保证属于目标表示、策略排序、学习速度，还是安全性？

### [平均奖励与差分价值](https://yingwen.io/zh/continual-rl/algorithms/average-reward/)

学习对象：长期奖励率与相对价值。

- 折扣价值 → 平均奖励与差分价值（改变目标）：先定义稳态奖励率。再减去该奖励率，描述暂态收益。
- 差分 TD → Differential Q / RVI（从预测到控制）：评价固定策略与求最优策略使用不同的后继值。常数偏移需要单独处理。
- 平均奖励控制 → RVI-SAC（扩展到近似连续控制）：critic 参照、熵项和重置成本共同规定目标，不能与折扣中心化混同。

思考：平均奖励相同的两个策略，短期收益可以不同吗？

## II · 状态构造与表征

### [智能体状态与递归学习](https://yingwen.io/zh/continual-rl/construction/state/)

学习对象：从历史构造的决策信息。

- 历史 → belief / 递归状态（构造状态）：已知模型可更新信念分布。未知模型可学习历史摘要。两者的充分性条件不同。
- 递归计算 → BPTT / RTRL / RTU（分配历史信用）：这些方法计算或近似参数对状态的影响。它们不是新的任务目标。
- 分段递归训练 → Memoroids / 完整序列与 RTRL（改变信用计算协议）：并行 scan 利用保存的序列。实时敏感度利用递推状态；训练内存与每步预算不同。

思考：内部状态变化和模型参数学习如何区分？

## III · 预测与预测知识

### [价值预测与资格迹](https://yingwen.io/zh/continual-rl/algorithms/value/)

学习对象：给定策略下的期望回报。

- 完整回报 MC → 一步 TD（改变估计方法）：TD 用当前预测替代尚未获得的未来回报。预测对象仍然不变。
- 一步 TD → n-step / TD(λ) / true-online（扩展信用时域）：多步目标与资格迹关联。在线参数变化决定前后向等价关系。

思考：一次 TD 误差小，是否说明价值误差小？

### [通用价值函数与预测知识](https://yingwen.io/zh/continual-rl/construction/predictive-knowledge/)

学习对象：行为条件下的累积信号预测。

- 奖励价值 → GVF（推广问题规格）：累计信号不必是奖励。目标策略与延续条件仍需明确。
- 单个预测器 → Horde；GTD / ETD（组织问题与选择学习器）：Horde 组织多个问题。GTD 与 ETD 处理特定离策略函数逼近问题。这是两个层次。
- 有限 cumulant 向量 → SF / FB / successor measure（扩大可查询的预测知识）：查询读出依赖占用约定、奖励特征和行为覆盖。
- 未来占用 → SF² 的生成式预测与控制特征（分开生成和读出接口）：向量场对条件特征线性，不保证下游价值线性。

思考：换累积信号与换更新算法，哪一种改变被预测的真值？

## IV · 控制与策略改善

### [持续控制与学习智能体比较](https://yingwen.io/zh/continual-rl/algorithms/control/)

学习对象：包括记忆与学习规则的持续行动过程。

- 固定 MDP 的策略评价与 GPI → 历史条件的完整学习器价值（扩大评价对象）：未来参数更新、信息获取与不可逆后果影响生命期表现。
- 最终策略分数 → 生命期效用 / 可行偏离比较（改变比较条件）：声明历史、时间、资源与比较器权限，不能直接对照不可实现 oracle。
- 自然终止与外部重置 → Continuing / reset-free / 可恢复控制（将恢复纳入时间轴）：重置后的状态、奖励和耗时是控制过程的一部分。

思考：当前值函数评价冻结策略，还是包含后续学习？

### [深度价值学习](https://yingwen.io/zh/continual-rl/algorithms/deep-value/)

学习对象：参数化动作价值。

- 表格 Q-learning → DQN（改变函数表示）：共享参数产生泛化，也会引入干扰。回放和目标网络分别调整数据与目标。
- DQN → Double DQN（分开选择与评估）：在线估计选动作。另一估计评价该动作。两者仍可能相关。

思考：误差来自目标、网络梯度，还是经验覆盖？

### [策略梯度与 actor–critic](https://yingwen.io/zh/continual-rl/algorithms/policy/)

学习对象：参数化行为策略。

- REINFORCE → baseline / actor–critic（改变梯度估计）：baseline 可降低方差。学得的 critic 提供价值或优势估计。
- 策略梯度 → GAE + PPO（组合估计与优化）：GAE 构造优势估计。PPO 优化裁剪代理目标。两者不是同一个改动。

思考：更新 actor 时，哪些路径求导，哪些权重需要固定？

### [最大熵控制](https://yingwen.io/zh/continual-rl/algorithms/soft-control/)

学习对象：带熵项的控制目标。

- 奖励最大化 → 最大熵控制（改变目标）：熵项改变最优策略和 Bellman 方程。温度规定两种收益的权重。
- 软策略改善 → SAC（组合近似与采样）：actor 近似改善步。双 critic、目标网络与回放支持实际训练。

思考：增加策略熵与提高外部任务回报是同一件事吗？

## V · 时间信用分配

### [时间信用分配与资格迹](https://yingwen.io/zh/continual-rl/algorithms/credit-assignment/)

学习对象：当前反馈与过去预测、动作及参数的关系。

- n-step / λ-return → TD(λ) / true-online TD(λ)（由前向目标到后向更新）：资格迹累积过去的梯度方向。冻结参数与在线参数下的等价关系不同。
- 预测信用 → SARSA(λ) / actor traces（用于控制）：行为策略和目标策略决定迹的含义。离策略更新不能直接套用同策略推导。
- 递归状态 → BPTT / RTRL（传播状态敏感度）：参数还通过过去状态影响当前输出。这条导数路径不同于奖励传播的时间尺度。
- 多步 TD 误差 → Tree-backup / Retrace / V-trace（区分传播与策略校正）：传播系数决定历史长度。误差中的比率决定目标；两者的截断不能互换。
- 采样的资格迹 → Expected Traces / 梯度资格迹（改变估计对象）：条件期望迹减少部分路径方差；梯度迹服务于明确的误差目标。两者使用不同假设。

思考：资格迹、循环状态和元敏感度分别记住了什么？

## VI · 流式学习与更新稳定性

### [流式更新与稳定性](https://yingwen.io/zh/continual-rl/algorithms/streaming/)

学习对象：有限数据存储和每步预算下的参数更新。

- 逐步 TD / actor–critic → Stream-X / ObGD / StreamingOptimizer（控制更新尺度）：归一化与过冲控制针对单步更新。不同论文版本的优化器不能混用。
- 参数空间更新 → Intentional updates（约束局部输出变化）：利用输出对参数的导数选择尺度。这不是沿学习历史优化外层目标。

思考：无回放、每步更新和无重置分别限制什么？

## VII · 元学习与学习规则的适应

### [元学习与学习规则的适应](https://yingwen.io/zh/continual-rl/algorithms/meta/)

学习对象：步长、学习目标、初始化或更新规则。

- 更新映射的链式法则 → IDBD / TIDBD / Metatrace（在线近似敏感度）：各方法保存不同的历史导数，并采用不同的近似。
- 可学习步长 → Meta-gradient RL（扩展适应对象）：用后续评价调整折扣或回报构造。内层学习目标与外层评价目标需要区分。
- 跨任务经验 → MAML / RL² / PEARL / learned rules（改变适应协议）：初始化、上下文和更新规则依赖不同的训练与测试协议。
- 在线敏感度更新 → TRAC / 算法元学习比较（区分局部适应和外部搜索）：在线调节尺度不等于通过未来回报做元梯度；元训练计算必须报告。

思考：方法改变的是当前状态、网络参数，还是学习规则？

## VIII · 子任务与时间抽象

### [目标条件化与子任务构造](https://yingwen.io/zh/continual-rl/construction/goals/)

学习对象：一族子任务与目标条件化策略。

- 单一任务 → Goal conditioning / UVFA / HER（扩展条件变量）：目标进入价值和策略。重标记经验还必须保持奖励与终止语义。
- 给定目标集合 → HIQL / MaestroMotif / 子任务构造（学习选择或构造）：层次选择已有目标与生成新目标是不同的问题。子任务用途由后续行为检验。

思考：子任务成功是否改善总体目标？

### [Options 与技能发现](https://yingwen.io/zh/continual-rl/construction/options/)

学习对象：可变时长的闭环行为。

- 原始动作 → Options / SMDP / Option-Critic（扩展决策单位）：启动、内部策略与终止共同定义行为。价值备份要处理随机时长。
- 给定技能 → Eigenoptions / DCEO / ALLO / METRA（发现行为）：谱结构、覆盖和方向约束提供不同的发现目标。它们不等同于主任务回报。
- 固定行为基 → Option Keyboard / OKB（学习组合并补齐行为）：组合训练不足与缺少必要基础必须分开检验。

思考：技能如何发现，如何执行，又如何评价其用途？

## IX · 模型学习与规划

### [Dyna 与模型学习](https://yingwen.io/zh/continual-rl/algorithms/dyna/)

学习对象：真实经验与模型生成的备份。

- 直接 RL + 模型学习 → Dyna（组合学习与规划）：同一条真实经验更新价值和模型。模型提供额外备份。
- 均匀模型采样 → Prioritized sweeping / search control（分配规划计算）：优先级改变备份顺序。模型失效仍需新经验纠正。

思考：收益来自更准确的模型，还是更多次备份？

### [转移模型与后果模型](https://yingwen.io/zh/continual-rl/construction/models/)

学习对象：一步或多步行为的后果。

- 一步转移模型 → Option 后果模型（扩展预测时域）：模型累计奖励，并描述折扣后的终点分布。随机时长留在期望内。
- 完整分布 → 期望特征模型 / SR / DR（限制模型接口）：不同表示支持不同的查询。只保存均值一般不足以计算非线性终点价值。
- 完整后果预测 → Value Equivalence / 分布模型等价（按规划查询决定充分性）：保持期望 backup 不保证保持风险敏感决策。

思考：模型保存的信息是否足以计算下游备份？

### [时间抽象与规划](https://yingwen.io/zh/continual-rl/construction/planning/)

学习对象：利用模型改善当前或后续决策。

- 原始动作备份 → 抽象模型备份 / ALPS（改变规划尺度）：多步模型可传播更远的价值。发现和维护这些模型也需要资源。
- 模型生成后果 → Dyna / MPC / Dreamer（区分计算用途）：Dyna 改价值。MPC 搜索当前行动。Dreamer 在想象轨迹中训练行为。
- 固定规划深度 → TD-MPC2 / 视觉目标 MPC（分配模型和价值的计算）：短期模型误差、终点价值误差与动作搜索误差需要分别诊断。

思考：规划预算按模型调用、计算时间，还是原始环境步统计？

## X · 长期适应、保留与探索

### [知识保留与再适应](https://yingwen.io/zh/continual-rl/algorithms/retention/)

学习对象：过去经验与已有能力。

- 持续参数更新 → Replay / CLEAR（复用数据与旧输出）：回放改变训练分布。离策略校正依赖原行为概率和环境条件。
- 共享参数 → EWC / 蒸馏 / 模块（限制干扰）：参数约束、输出约束和结构隔离保存不同对象，也有不同代价。
- 保护旧输出 → 效用保护 / 功能保持与再学习（区分保留和学习条件）：能快速学新任务与保持旧行为不是同一个指标。

思考：应保留哪些能力？哪些旧行为应该放弃？

### [可塑性与特征更新](https://yingwen.io/zh/continual-rl/algorithms/plasticity/)

学习对象：学习新规律的能力。

- 长期函数逼近 → ReDo / Continual Backprop（更新特征集合）：重置与替换改变可用特征。效用指标和优化器状态影响实际更新。
- 优化与尺度变化 → NaP / 干扰诊断（定位学习退化）：特征失活、尺度与目标干扰是不同解释。诊断需要相应对照。
- 低效用特征替换 → UPGD / Parseval（干预效用与几何）：保护重要方向、注入扰动与维持权重条件各有机制和代价。

思考：旧任务成绩正常，是否足以证明可塑性正常？

### [探索与经验选择](https://yingwen.io/zh/continual-rl/algorithms/exploration/)

学习对象：行动产生的后续经验。

- 随机尝试 → 乐观估计 / 新奇 / RND（利用额外行为信号）：这些信号分别描述不确定性或访问新奇，不能与任务价值混同。
- 原始动作探索 → 技能探索 / 自动课程 / LSAC（改变探索结构）：技能改变时间相关性。课程改变训练问题。参数采样改变策略或价值估计。
- 任务内探索 → CPSRL / MoReFree（不依赖环境回合重置）：模型重采样不是重置环境；恢复与目标调度需计入真实时间。

思考：访问更多状态是否带来更多有用学习？

## XI · 持续学习的智能体架构

### [持续学习的智能体架构](https://yingwen.io/zh/continual-rl/construction/architectures/)

学习对象：相互作用的学习模块。

- 状态 + 策略 + 价值 + 模型 → Dyna / STOMP（明确模块接口）：子任务产生行为。行为产生后果模型。模型通过规划影响控制。
- 给定模块集合 → OaK 的生成与选择问题（研究资源分配）：持续构造、评价和替换知识是架构目标。组件结果不等于完整系统结果。
- 功能模块组合 → 知识依赖与资源预算（明确可维护的接口）：表示、策略或目标变化会使后果知识过期；维护成本属于完整系统。

思考：删除一个模块后，应改变哪个中间量与最终量？

## XII · 强化学习实验方法

### [实验设计、统计与算法测试](https://yingwen.io/zh/continual-rl/experiments/)

学习对象：结论对应的估计量与比较程序。

- 数学更新 → 手算 / 单元测试 / 梯度检查（验证实现）：正确实现是性能比较的前提，不是性能提升的证据。
- 候选算法 → 开发选择 → 独立测试（控制选择偏差）：调参预算属于比较条件。置信区间必须尊重独立运行这一随机单位。

思考：当前实验支持实现、机制、性能还是长期学习能力的结论？

## 跨章节关系

- 转移模型与后果模型 → 交互、奖励与优化目标：风险目标要求不同的后果统计；均值模型未必足够
- Options 与技能发现 → 知识保留与再适应：技能或停止规则变化后，旧后果知识可能过期
- 时间信用分配与资格迹 → 可塑性与特征更新：信用方向与学习几何共同决定新经验能否改变网络
- 奖励假设与奖励设计 → 元学习与学习规则的适应：可微奖励设计沿学习过程优化外部表现；不等同于策略不变塑形
- 交互、奖励与优化目标 → 奖励假设与奖励设计：总体偏好需要一个可检验的奖励机制
- 奖励假设与奖励设计 → 持续控制与学习智能体比较：控制优化所给信号；另需评价是否符合意图
- 奖励假设与奖励设计 → 目标条件化与子任务构造：子任务奖励应服务于总体评价
- 奖励假设与奖励设计 → 智能体状态与递归学习：时间结构可能要求奖励状态与记忆
- 价值预测与资格迹 → 时间信用分配与资格迹：多步预测目标给出时间信用分配的前向视角
- 时间信用分配与资格迹 → 流式更新与稳定性：资格迹使部分历史信用可逐步计算
- 时间信用分配与资格迹 → 元学习与学习规则的适应：元梯度还需追踪学习过程对元参数的依赖
- 流式更新与稳定性 → 元学习与学习规则的适应：相同数据协议下可比较固定规则与元学习
- 交互、奖励与优化目标 → 持续控制与学习智能体比较：优化目标规定策略比较准则
- 智能体状态与递归学习 → 通用价值函数与预测知识：状态提供预测的条件信息
- 通用价值函数与预测知识 → 智能体状态与递归学习：学得预测可以参与状态构造
- 价值预测与资格迹 → 持续控制与学习智能体比较：策略价值支持策略改善

## 交叉的数据和交互设定

### 离线 RL 与 offline-to-online

行为约束 / CQL / IQL / Decision Transformer。CQL 通过保守价值估计缓解数据外动作的过估计；IQL 避免训练时查询数据集外动作来学习价值；序列建模是另一种从轨迹提取策略的路线。转入在线阶段后，还需处理探索、数据混合和表示适应。

有 replay 不等于 offline；预训练后在线微调也不自动证明长生命期 CRL。

[Levine 等 · Offline RL 教程](https://arxiv.org/abs/2005.01643)

### Meta-RL、快速适应与任务推断

RL² / MAML 风格优化 / 上下文推断。外层训练塑造跨任务的适应过程；内层可表现为参数更新或递归状态变化。它与终身更新能组合，但必须说明外层与内层哪些东西持续改变。

在固定元训练分布上快速适应，不保证面对持续新任务仍积累能力。

[Duan 等 · RL²](https://arxiv.org/abs/1611.02779)

### 多智能体、伙伴适应与自博弈

独立学习 / 集中训练分散执行 / 自博弈。伙伴或对手也在学习，会使单个 agent 看到的经验分布变化。价值分解、critic 可用的信息和训练人口管理是不同设计位置；MARL 可与 PPO、actor–critic 和模型方法相交。

由其他 agent 更新造成的非平稳性，不等于显式任务切换；需区分队友泛化、对手适应与遗忘。

[任务推断、伙伴适应与元学习导读](/zh/continual-rl/research/R09/)

### 分布式与大规模数据收集

A3C / IMPALA / Ape-X / R2D2。多个 actor 与 learner 的速度不同，会产生策略滞后；IMPALA 的 V-trace 用于相应的 off-policy 校正。吞吐量、数据复用和更新延迟需要分别记录。

分布式 distributed 不是分布价值 distributional；训练更久、并行更多也不自动构成 CRL。

[Espeholt 等 · IMPALA](https://arxiv.org/abs/1802.01561)
