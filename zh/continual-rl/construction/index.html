    知识、行为与模型的构建

    先区分每个模块学习的对象。再分析模块之间的信息传递。状态、预测知识、子任务、技能和模型具有不同的定义。它们可以在同一经验流上学习。

    LEARNING OBJECTS & INTERFACES

    知识构建关系图：学到的对象怎样服务下一步？

    知识保留与可塑性影响长期学习能力。预测、技能发现与模型学习产生可用于决策的知识。完整智能体需要协调这些过程。

    问题 ≠ 行为 ≠ 后果
    “累计耗电多少”是 GVF 问题；“到充电站”是子任务；“如何走并何时停”是 option；“耗电、时长与终点分布”是 option model。

    共同约束，不是额外一块
    遗忘、可塑性、off-policy 稳定性、实时信用分配和有限资源，作用于上述每个模块。

    学习对象与整体架构

    Agent state：部分可观测性、递归记忆与在线信用分配任务目标给定以后，智能体应当保留哪些历史信息，才能预测未来并选择动作？→通用价值函数与预测知识同一张地图既能问“向左会成功吗”，也能问“还要走几步”。怎样规定这些问题，从一条经验流学出答案，再让决策用上它们？→目标与子任务：条件控制、经验重用与技能设计怎样让同一套控制器应对不同目标、从未成功的尝试中学习，并选择对未来控制有用的子任务？→Options：多步决策、技能发现与可复用行为怎样把连续多步的行为当成可复用的决策单位，同时仍能在每个原始时间步学习？→模型与后果预测：学什么，才能用于下一次决策？执行一个动作或技能以后，会积累多少奖励、何时到哪里；这些预测怎样支持规划与任务变化后的迁移？→规划：把模型中的经验转成更好的决策真实交互很贵、计算预算有限时，怎样决定想象什么、更新什么，以及何时应该不再相信模型？→持续智能体架构：模块接口、更新调度与长期评价各模块单独能学，不代表接在一起就能持续改善；它们究竟交换什么、何时更新、如何共享有限计算？→

    架构不是按年份互相取代：看清学了哪一部分

    下表比较学习对象和接口，不把所有相关工作都归为直接的 CRL 算法。

    架构 / 路线主要学习对象哪些仍给定关键连接如何解读
    Dyna价值 + 模型；模拟更新改进控制状态、动作与主奖励通常给定模型支持 learning-time planning不是自动生成状态、目标与技能的完整系统
    Horde共享经验流上的多个预测器预测问题与表示通常由设计者给定同一 transition 回答多个问题多预测器不等于自动选择有用问题
    UNREAL主任务 actor–critic + 辅助学习辅助任务类型由设计者规定共享表示与辅助控制/预测辅助学习不自动构成长期自主知识发现
    Dreamer / Director潜在模型、行为；Director 加入层次目标模型结构、训练协议与高层接口有设计约束想象学习；manager/worker 目标传递有运行实现；不等于全部 OaK 接口或 strict streaming
    ROD / skills-to-symbols分别强调表示—技能反馈与技能支持的符号抽象候选结构、输入信息与实现设置各有假设抽象如何影响下一轮经验或高层规划两条相关路线，不是同一个架构的前后版本
    STOMPSubTask → Option → Model → Planning给定特征；子任务与停止奖励的设计将学到的技能后果放进规划组件与特定实验不等于自主状态/目标发现全部完成
    Alberta Plan / OaK持续表示、控制、抽象知识与规划的研究路线需要把各个假设逐步变成可学习接口期待形成知识构建与控制效用的闭环路线图、公开机制与整体系统结果要区分

    四个可逐步扩展的研究起点

    以下是研究练习，不预先声称方法新颖性。先检索近邻论文，再用消融确定机制。

    A · 预测多了，控制真的更好吗？

    固定 TD 底座，只改变预测问题集合；设有用、无关、随机三组。

    看什么：预测误差 + 控制收益 + 每步更新预算。

    下一步：先固定问题，再研究根据下游用途增删问题。

    B · 为什么这个子任务值得存在？

    同一个门口目标，对比 shortest-path 与 reward-respecting 定义。

    看什么：沿途真实代价、到达率、技能学习成本、后续规划收益。

    下一步：再从多个候选门口中选择，最后才研究候选如何生成。

    C · 技能改进了，规划为什么反而退步？

    冻结环境与表示，只改 option policy 或终止；比较旧模型与重估模型。

    看什么：终点/奖励/时长预测误差、Bellman target 偏差与恢复。

    下一步：再允许表示一起变化，分离两种模型失效来源。

    D · 知识库应该增长还是淘汰？

    设置固定技能/模型容量，对比随机替换、使用频率与规划效用代理。

    看什么：后续学习曲线、罕见任务回归表现、维护成本。

    下一步：不把代理分数当真实长期效用；加入资源匹配消融。

    与目标、长期学习和实验连接

    先明确 优化目标。用 信用分配分析反馈如何更新参数。用 实验设计区分实现正确性、机制作用和长期性能。扩展资料见 主题目录。
