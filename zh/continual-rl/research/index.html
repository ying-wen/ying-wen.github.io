评价的是最终策略，还是整个学习生命期？

奖励表示与奖励学习：目标怎样进入智能体？

奖励假设与奖励设计 →交互、奖励与优化目标 →智能体状态与递归学习 →持续控制与学习智能体比较 →目标条件化与子任务构造 →实验设计、统计与算法测试 →

问题设定。设计者拥有偏好，智能体只能接收有限观测和奖励。奖励可能手写，也可能由人的比较或示范推断。必须分开目标变化、奖励估计变化与环境变化。

已有认识。期望效用与局部加性奖励需要不同条件。势函数塑形在边界条件满足时保持策略排序；偏好模型可以从片段比较中学习。

尚缺什么。新行为会改变奖励模型的数据分布。有限反馈下，怎样保持奖励语义并防止代理失效仍是开放问题。

01 · 什么目标能够评价一个始终在学习的智能体？

交互、奖励与优化目标 →持续控制与学习智能体比较 →平均奖励与差分价值 →实验设计、统计与算法测试 →

问题设定。智能体只有有限存储和每步计算时间。学习改变其后续行为，环境可能持续而不终止，也可能存在成本不为零的重置。比较前需规定奖励、时间单位、评价时域和可用干预。平稳环境仍可能对有限资源智能体提出长期学习需求。

已有认识。折扣回报、有限生命期累计奖励和长期平均奖励并非同一个目标。平均奖励消除人为终止对目标的部分影响，但忽略有限前缀的长期极限也可能掩盖高昂适应成本。Abel 的持续性定义与 history-process 研究进一步把学习过程本身纳入讨论。

尚缺什么。仍需要连接渐近算法理论、有限寿命在线效用与真实时间成本。把折扣设为接近一，不能自动得到差分价值算法；平均奖励表现好，也不能单独证明智能体一直在累积有用能力。

方法线改变什么，为什么可能有效成立条件与代价
Differential TD/Q → RVI-SAC
原文1 ↗原文2 ↗
 差分 TD 用 Rt+1−rˉtR_{t+1}-\bar r_tRt+1​−rˉt​ 替代未中心化奖励，联合更新奖励率与相对价值。RVI-SAC 进一步把平均奖励目标接到熵正则 actor–critic，并处理 reset cost。表格收敛定理不直接覆盖非线性深网或任意漂移。RVI-SAC 的 replay 和目标网络也不属于严格 streaming 协议。
Reward centering 与协议比较
原文1 ↗
 从折扣 critic 中分离共同奖励偏移，减少无关基准对数值尺度的影响；同时显式比较三种 reset 协议。改变估计方法不必然改变任务目标。奖励中心化、平均奖励优化和延长 episode 是不同干预，实验不能将三者同时改变后只归因于平均奖励。
History process / deviation regret
原文1 ↗原文2 ↗
 用交互历史刻画问题，并通过允许的行为偏离比较实际学习过程。评价对象不再只是训练完成后的一个策略。必须规定偏离集合、可观测信息和估计条件；这是一条形式化路线，而非已统一整个领域的标准。

相互竞争的解释

  • 方法收益可能来自更合适的任务目标，也可能只是奖励中心化改善了数值条件。
  • 高终局成绩可能伴随更长探索期；高在线平均分也可能来自初始先验，而非更强持续学习。

一个可执行的判别实验

待检验假设
算法排序的一部分差异由目标与 reset 权限造成，而不是网络表达能力造成。
实验设计
从教材循环奖励例子开始，解析比较折扣与平均奖励的策略排序；随后固定同一控制环境，分别改变折扣、奖励常数偏移和 reset 成本，每次只改一项。
必要对照
同网络、数据预算、种子与调参次数；记录 reset 是否由 agent 决策。设置不学习、固定步长学习和对应平均奖励方法。
测量对象

什么结果会反驳该解释
在匹配目标、中心化与重置条件后排序差异消失，就不支持“目标形式本身带来普遍收益”的解释。

历史中的哪些信息应当成为可用知识？

02 · 有限的内部状态应当保留哪些历史信息？

智能体状态与递归学习 →通用价值函数与预测知识 →时间信用分配与资格迹 →

问题设定。当前观测不能唯一决定后续结果。智能体从历史构造内部状态，但内部状态维度、计算和信用传播长度受限。环境的隐藏状态、网络活动、可学习参数以及 replay buffer 是不同对象。

已有认识。状态更新 ht+1=fθ(ht,At,Ot+1)h_{t+1}=f_\theta(h_t,A_t,O_{t+1})ht+1​=fθ​(ht​,At​,Ot+1​) 只规定如何压缩历史，不保证压缩后具有 Markov 性。控制充分性允许丢掉与最优决策无关的信息；完整预测充分性通常更强。递归结构和用于训练它的目标需要分别选择。

尚缺什么。仍缺少在相同信息、容量和延迟条件下，对“保留什么”与“怎样学会保留”作出明确归因的证据。更长记忆也可能存下无关历史；表示不断改变还会让依赖它的 critic 和模型失效。

原文1 ↗
 历史堆叠显式保留固定窗口；门控递归通过活动延续信息。BPTT/TBPTT 则决定参数能够接收到多远的训练信用，不能由 hidden state 不清零推断信用也没有截断。要匹配观测历史权限和实际训练窗口。完整回放序列、缓存 hidden state 与纯逐步处理具有不同成本。

 将递归坐标与一组可由经验检验的预测联系起来，以预测误差训练状态。它回答“内部坐标应携带什么”，而不仅增加网络容量。选择的问题必须能被数据覆盖，并对下游有用；有限预测集合不会自动成为充分状态。
RTU → 部分可观测 streaming RTRL
原文1 ↗原文2 ↗
 结构化递归使参数对状态的敏感度可以逐步维护。近期工作把该敏感度与控制资格迹结合，同时研究在线权重变化造成的敏感度陈旧。高效精确计算依赖递归结构；不是任意 RNN 都能在线性成本下完成 RTRL。2026 工作仍是预印本。

相互竞争的解释

  • 提高回报可能来自额外历史信息，而不是更好的表示学习目标。
  • RNN 比前馈网络好，可能只是在隐式推断任务标签；也可能真正记住了任务内关键事件。

待检验假设
预测式内部状态在相同容量下更容易保留决策所需的稀疏历史事件。
实验设计
先做延迟线索记忆链，分别改变线索延迟、无关观测和任务切换；再在 Forager 中只改变一个观测模式。对状态做冻结线性探针，但不把探针数据反馈给 agent。
必要对照
同参数量、动作信息与每步延迟预算；前馈、固定窗口、GRU/RTU、加预测损失各自单独比较。
测量对象

什么结果会反驳该解释
匹配历史窗口后收益消失，或能预测关键事件却不改善决策，就不能归因于更好的控制状态。

03 · 哪些预测值得学习，谁来使用这些预测？

价值预测与资格迹 →通用价值函数与预测知识 →智能体状态与递归学习 →元学习与学习规则的适应 →

问题设定。同一数据流可以支持许多不同未来问题。计算和容量有限，行为策略也未必覆盖每个目标策略。核心研究对象不仅是一个预测器的误差，还包括问题的选择、淘汰与下游用途。

已有认识。一个 GVF 由累积信号 ccc、延续条件 γ\gammaγ 和目标策略 π\piπ 指定。TD、GTD 与 emphatic 方法是回答该问题的算法。GVF 的定义不要求其参与状态，也不要求其信号就是任务奖励。

尚缺什么。预测学得准，并不表示它能改善主任务。辅助目标可能利用额外数据，也可能与主目标争夺表示容量。发现有用问题还要平衡可学习性、未来复用和当前计算成本。

04 · 旧价值什么时候应该复用，什么时候应该快速改写？

持续控制与学习智能体比较 →深度价值学习 →策略梯度与 actor–critic →最大熵控制 →知识保留与再适应 →

问题设定。策略改善不断改变数据分布。奖励或动力学还可能发生外部变化。一个旧价值函数既可能提供知识，也可能阻碍适应；仅靠最终价值误差不能判断控制失败的原因。

已有认识。Q-learning、actor–critic 和最大熵控制规定不同的策略改善步骤。CRL 并不取代这些控制骨干，而是要求其在持续变化的数据和有限经验预算下继续有效。环境变化速度与估计速度的关系比算法名称更重要。

尚缺什么。“快忘记”和“保留长期规律”存在冲突。显式任务边界下的重置或压缩不一定能用于边界未知的情形；环境不变时，由策略改善产生的数据漂移也会触发类似现象。

05 · 远处的反馈应该怎样更新早先的决策与内部计算？

时间信用分配与资格迹 →价值预测与资格迹 →智能体状态与递归学习 →策略梯度与 actor–critic →

问题设定。关键线索或动作很早出现，奖励很晚到达。时间信用涉及不同时间步；结构信用涉及同一计算图中的参数与中间量。是否只能在线更新，是另一个资源条件。

已有认识。冻结参数时，λ\lambdaλ-return 的总增量可改写为 TD 误差乘资格迹的后向更新。传统在线 TD(λ\lambdaλ) 在每步改变参数后不再精确保持该恒等式。True-online TD 重新定义在线前向目标并加入荷兰迹与修正。

尚缺什么。深度控制需要同时处理非线性表示、离策略数据、递归状态和权重变化。把一条 trace 加到 optimizer 中不足以证明它解决了长时域信用，也不能将 RTRL 敏感度直接当作价值资格迹。

方法机制与成立条件

方法线改变什么，为什么可能有效成立条件与代价
n-step / λ-return / true-online TD
原文1 ↗
 多步目标在不同 bootstrap 长度之间混合。后向资格迹压缩过去预测的梯度方向；true-online 的额外预测修正使指定线性算法对应逐前缀前向参考。精确等价针对定义好的线性、固定特征、步长等条件。更大 λ 会延长信用，也会增加误差与方差传播。
控制中的资格迹
原文1 ↗
 SARSA 的 bootstrap 使用实际选择的下一动作；Watkins Q(λ) 使用 max target，并在下一行为非贪心时剪断后续迹。剪迹发生在当前反馈完成信用分配之后。两种方法目标不同；不能把任意 off-policy actor–critic 都用同一个剪迹规则替换。
RTRL 敏感度 × 价值/策略时间信用
原文1 ↗原文2 ↗
 RTRL 追踪参数对当前内部状态的影响；外层 TD 或策略更新还需要把延迟反馈与预测/动作联系起来。结构化递归研究使这两个层次可以在有限预算下组合。在线参数变化使全历史敏感度产生陈旧误差；截断和低秩近似又带来不同偏差或方差。

相互竞争的解释

  • 提高 λ 后变好，可能只是有效步幅变大，而不是利用了更久以前的信息。
  • 更长反传窗口有效，可能来自更多重复训练，而非更准确的历史因果路径。

06 · 不存 replay、每步只处理新经验时，怎样避免更新失稳？

流式更新与稳定性 →时间信用分配与资格迹 →策略梯度与 actor–critic →最大熵控制 →

问题设定。数据到达后立即用于学习；过去 transition 不被存储再训练。资格迹、递归活动和 optimizer 状态仍可存在，但须计入内存。数值稳定、样本利用率和动作 deadline 都是评价对象。

已有认识。逐步更新时，样本间的相关性和瞬时尺度不会被 batch 平均掉。归一化、网络尺度、资格迹与 actor–critic 时序会共同影响稳定性。“batch size=1”只是数据粒度，不是一套完整算法。

尚缺什么。稳定参数步幅不等于稳定输出，更不等于稳定长期控制。不同网络、奖励尺度和罕见大误差下的适用条件仍需检验；单步更新便宜也可能因为需要更多真实经验而整体昂贵。

07 · 哪些学习参数应当适应，怎样评价学出来的更新规则？

元学习与学习规则的适应 →时间信用分配与资格迹 →流式更新与稳定性 →实验设计、统计与算法测试 →

问题设定。权重在内层学习，步长、return 参数、初始化或整个更新器在外层适应。在线元学习使用一段持续经验；跨任务元 RL 使用任务分布及重置。两者的元目标和数据权限不同。

已有认识。IDBD 用步长敏感度选择特征的学习尺度；TIDBD 把该思路带到 bootstrap 预测。Metatrace 将元敏感度与 actor–critic 的时间信用结合。Meta-gradient RL 更一般地对学习过程求导，学习 return 等参数。

尚缺什么。短展开元梯度可能优化短期可见效果，而不是长期适应。学出的规则可能依赖元训练时域、任务分布和网络尺度；有限任务上的泛化不能保证无限生命期收益。

08 · 什么样的时间抽象值得加入技能库？

问题设定。Option 具有启动条件、内部策略与终止规则。技能发现还要决定哪些 option 值得占用容量。探索覆盖、执行效率、信用压缩和规划价值是不同用途，不能仅凭技能数量或轨迹图判断。

尚缺什么。技能发现的计算和交互成本往往在下游成功率之外。环境或表示改变后，旧技能的启动、终止与后果模型都可能失效。持续技能库还缺少可靠的保留、合并、替换和重估准则。

09 · 子目标从哪里来，为什么学习它能帮助总体任务？

目标条件化与子任务构造 →交互、奖励与优化目标 →Options 与技能发现 →

问题设定。总体任务奖励已经给定。智能体还可以选择中间状态、预测目标、技能描述或训练课程。定义目标、学习目标条件策略、选择当前目标是三层计算，不应都称为“目标发现”。

已有认识。UVFA 提供目标条件价值接口；HER 从失败轨迹重标记可达目标；HIQL 将长期任务分解为高层目标和低层动作。它们主要解决已给目标下的学习和组合，不能单独回答哪些新目标值得创造。

已有认识。对于线性下游价值，适当的期望后果有时足以完成 backup；非线性价值、max 运算或风险目标一般不能只保留一个均值。世界模型、successor features 和 option model 的条件行为与输出语义不同。

尚缺什么。持续学习会产生接口失配：旧模型预测旧表示，规划却读取新表示；option 政策更新后，其终点与时长分布也会改变。高平均预测精度可能掩盖极少发生但决定策略排序的错误。

11 · 什么时候值得规划，应该把计算花在哪里？

Dyna 与模型学习 →转移模型与后果模型 →时间抽象与规划 →Options 与技能发现 →

问题设定。规划用已学模型进行额外计算。真实交互、模型更新、搜索和想象训练共享有限预算。问题不是简单地增加规划步数，而是选择何时、何处、以什么时间尺度使用模型。

12 · 怎样保留旧能力，而不把过时知识强加给新任务？

知识保留与再适应 →持续控制与学习智能体比较 →转移模型与后果模型 →实验设计、统计与算法测试 →

问题设定。学习分布变化后，旧任务能力可能下降。保存旧轨迹、生成旧经验、保持旧策略或分配独立模块都可以减少遗忘，但也可能减慢适应。任务边界和回访权限决定哪些方法可用。

已有认识。Replay 保留数据，蒸馏保留函数输出，参数正则保留局部参数几何，生成模型保留经验分布。它们保存的对象不同。低遗忘不等于高前向迁移，快速新学习也不等于旧知识保存良好。

尚缺什么。多数任务序列允许明确边界与评估重置，持续无边界条件更难分清“旧知识”与“已失效的规律”。固定容量下应保留哪些知识，仍取决于未来用途和重学代价。

13 · 为什么训练越久，学习新东西反而越慢？

可塑性与特征更新 →知识保留与再适应 →深度价值学习 →

问题设定。长期训练后的网络面对新的可学习目标，下降速度比新初始化更慢。需在相同数据和目标上比较 aged 与 fresh 网络，才能把优化能力下降和探索失败区分开。

已有认识。休眠单元、参数尺度、有效学习率、损失几何和预测函数剧烈变化都可能参与可塑性损失。单一活动度或参数范数是诊断变量，不是可塑性的完整定义。

尚缺什么。一个机制在监督漂移或特定控制环境有效，不代表它解决了长期交互。替换单元改善新学习时，可能损坏旧功能；约束函数变化又可能拖慢必要的适应。

方法机制与成立条件

原文1 ↗原文2 ↗
 ReDo 以低活动度发现可回收单元；CBP 结合效用、成熟期和替换预算引入新特征。替换涉及输入、输出连接与 optimizer 状态。单位替换量、初始扰动和实际参数预算必须匹配；激活率提高不证明新任务学得更快。
Normalize-and-Project
原文1 ↗
 归一化网络中，权重范数增长会改变有效学习率。NaP 将归一化与权重投影结合，使这一隐含调度可被显式研究。保持有效学习率不必在所有任务最好；原文也分析隐含衰减何时有帮助。
C-CHAIN：减少函数 churn
原文1 ↗
 在参考状态上限制近期更新造成的全动作 Q 变化，以减轻一个数据片段对其他预测的干扰。它干预的是函数变化，而不是直接重置单元。需要参考数据与近期网络；正则过强可能妨碍合理策略变化，且不满足无 replay 的最严格协议。

14 · 应当探索什么、练习什么，以及如何保留未来交互与学习的机会？

已有认识。预测误差可以鼓励访问未熟悉状态，学习进展可以优先分配可改善任务，恢复策略可以减少陷入失能状态的风险。但噪声环境可能永远产生大误差，短期安全也不等于长期可恢复。

15 · 状态、知识、技能与规划怎样共同构成持续智能体？

问题设定。完整 agent 同时更新状态、预测、控制、技能与模型。每个局部学习器看到的输入和目标都可能被其他模块改变。整体表现还受内存、计算分配和数据获取限制。

16 · 什么实验能区分“仍在更新”与“仍在有效学习”？

实验设计、统计与算法测试 →交互、奖励与优化目标 →持续学习的智能体架构 →可塑性与特征更新 →知识保留与再适应 →

问题设定。一条长曲线包含适应、探索、保留、环境变化和随机波动。训练中评估可能重置环境或暂停更新，这些操作会改变单生命期。研究需要先确定估计量与独立随机单位。

已有认识。在线奖励评价实际学习过程；冻结策略诊断回答某个时间点会做什么；回访与新目标探针分别测试保留与可塑性。一个指标不能代替另外几个。跨种子区间与多任务稳健聚合有助于避免只看最好结果。

尚缺什么。有限实验不能证明永远持续改善，但可以排除明确失败解释。领域仍需要跨协议可比较的报告：真实时间、内存、全部训练成本、重置权限、变化来源及模型版本，而不仅是最终归一化均分。

长期评测与失败边界

先把问题说清

  1. 一生的“学得好”到底指什么？

    终局测试很高，但适应时损失巨大，或者依赖免费重置。

诊断为什么学不好

  1. 规律变了，怎样及时发现并改正？

    旧估计非常稳定，却迟迟跟不上新奖励或新动力学。

  2. 当前画面不够，应该记住什么？

    相同观测需要不同动作；更大的前馈网络仍做错。

  3. 新知识怎样不破坏仍有用的旧知识？

    学完 B 后，在相同协议下重新测 A，A 的表现下降。

  4. 训练久了，为什么新东西越来越难学？

    老网络获得相同新数据和预算，却比合适的 fresh 参照学得慢。

  5. 每步预算很小，怎样可靠地分配信用？

    实时更新发散、梯度延迟太长，或者一个环境步用了大量隐含回放。

把经验变成可复用能力

  1. 经验该变成哪些预测，才能在未来派上用场？

    奖励之外的规律反复重学；辅助损失下降却没有改善决策。

  2. 怎样形成可复用的目标与长行为？

    每个任务都从原始动作重新探索，技能库却越积越多而用不上。

  3. 怎样用后果模型减少真实试错？

    模型内预测很好，现实行为却错误；规则变后越规划越自信。

让学习持续，并检验系统

  1. 接下来学什么、去哪探索，还能否安全回来？

    永远遇不到新证据，或者探索一次就失去后续交互与学习的机会。

  2. 能不能让学习过程本身越用越合适？

    每次换环境都重新调步长，或者短期学得快却长期不稳定。

  3. 把模块接起来，怎样证明真的在持续积累？

    每个模块单测正常，整机却没有长期收益，结论只剩一条平均曲线。

理论定义、非平稳 MDP 与任务序列研究采用不同条件。比较方法时，需要共同说明环境变化、可观察信息和经验使用协议。

问题边界：目标、交互协议和变化来源是三条独立轴；不是看到 continual 就必须使用某一个算法。

可分别研究的子问题

  • 优化折扣收益、平均奖励率，还是一段生命期的累计效用？
  • 变化发生在奖励、动力学、观测、动作集合，还是学习器自己诱导的数据分布？
  • 任务 ID、边界、reset、replay、预训练经验各允许什么？
算法线实际改变什么成立条件与代价
折扣 / 有限时域 / 平均奖励改变如何评价未来与时间代价平均奖励需要相应的遍历/通信等假设，并不自动解决变化。
非平稳 MDP / 潜在情境 POMDP前者描述外部随时间改变；后者把未观测情境纳入状态同一表象可以有不同模型，不要混用各自理论保证。

问题定义、长期目标与理论

我们研究的是任务序列、环境变化、有限智能体的持续学习，还是不能重置的生命史？不同答案决定不同算法和评测。

如何把抽象的持续学习定义转成可测、可比较、不会奖励无效变化的长期能力指标？理论中的 agent class 与实际可训练系统之间还有距离。

遗忘、可塑性与持续适应

新任务表现差，究竟是旧知识干扰、状态表示不对、网络失去可训练性，还是学习目标突然改变？

何时替换、替换什么、怎样估计未来效用？能否在没有任务边界、有限容量和较长生命史下同时积累能力与维持适应？

逐步更新、实时学习与信用分配

只拿最新 transition、不能依赖大 batch 和 replay 时，深度控制怎样稳定更新？长时间依赖的梯度又怎样及时计算？

如何同时满足长信用视野、真实时间、稳定性与长期可塑性？严格在线假设下的结构约束是否限制表示能力？

预测知识、内部状态与部分可观测

当前观测不足时，怎样从历史构造对预测和控制有用的 agent state，而不是无限保存原始经历？

怎样自主产生、评估、删除预测问题？预测数量增长能否转成控制与迁移收益，而不超过固定存储和每步计算？

表示、技能发现与抽象组合

长期交互中怎样发现、组合并维护技能与抽象，而不是每个新任务从原始动作重新学习？

表示在漂移、技能会失效、环境拓扑也会改变：怎样同时更新技能和模型，并在有限容量下判断哪项能力还值得保留？

世界模型、背景规划与决策时搜索

学到的模型怎样帮助决策？更多搜索改善的是这一次行动，还是经由更新形成以后可复用的能力？

模型更新后旧技能与搜索结构如何同步？如何在相同总计算下分配模型学习、背景更新和在线规划，而不是用更多算力掩盖缺陷？

探索、自动课程与开放式学习

agent 如何选择值得学习的目标和经历，而不是持续重复已经掌握、或根本学不动的任务？

没有未来测试集信息时，怎样评价一段经验的长期价值？教师自身如何适应，能力增长怎样在固定资源下被测量？

单生命期、无重置与机器人终身学习

不能随意重置身体或环境时，怎样在犯错、恢复、任务变化和人工维护之间持续学习？

恢复与探索怎样共同优化？在没有任务边界、不能倒带、硬件和世界都会漂移时，如何保持安全且继续形成新能力？

任务推断、伙伴适应与元学习

任务或交互伙伴变化时，怎样利用旧经验快速适应，同时避免只适合固定训练分布？

如何避免外层训练任务分布替 agent 预先解决全部结构发现？适应新伙伴是否牺牲旧伙伴兼容性？外部记忆到底留下了何种可校正能力？

Benchmark、实验设计与研究证据

最后一个平均分，是否掩盖了后期学不动、任务不匹配、过度调参、更多计算或失败运行？

有限生命期实验如何支持长期能力主张？如何避免用整个未来任务序列调参，以及把大量外层搜索隐藏在一次 agent 运行之外？

把研究问题写成实验协议

先提出至少两种解释。再选择能区分解释的干预。最后固定开发程序、确认实验和失败处理方式。单一基准的均值提升不能替代机制论证。
