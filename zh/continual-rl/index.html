从强化学习的基本问题出发，研究有限智能体在长期交互中如何构造状态、预测后果、改善行为，并维护学习能力。教材、研究问题与实验按同一套概念结构组织。

THE REINFORCEMENT LEARNING PROBLEM

研究起点：通过交互学习以实现目标

先定义交互接口、未知量、信息权限、候选解和评价准则，再推导求解机制。强化学习的动作影响奖励、后续情境与能学到的经验；持续强化学习进一步研究有资源限制的智能体如何在长期交互中适应。MDP、目标函数、深度方法与持续学习分别改变不同条件，需要逐项说明关系。

本书先讲一般强化学习的目标、预测、控制和规划，再讨论有限智能体在大世界中如何构造状态、维护知识与持续适应。表格与深度方法提供可复用的工具；它们与持续强化学习并非互斥类别。

从强化学习基础到持续学习

智能体通过行动获得经验。学习改变它对未来的预测，也改变它的行为。本教材依次区分优化目标、状态、预测和控制，再讨论更新规则、时间抽象与规划。算法谱系使用相同的章节结构。

第一遍的主线：整体问题 → 定义目标 → 设计奖励 → 评价策略 → 比较完整学习器 → 检验算法。

尚未学过策略改善，可先读表格分册中的动态规划和采样控制。主线控制章进一步研究学习过程、历史条件与单次生命期比较。状态、信用分配、GVF 和元梯度按所选问题继续阅读。

已有 DQN / PPO 经验：先明确目标、状态和数据权限。再进入对应研究分支。实验方法可以与任一章节配合阅读。

  1. I

    强化学习问题与目标

    从智能体与世界的持续交互出发，区分外部设计者的偏好、实际奖励和评价准则。奖励是假设与设计的对象，不是结果好坏的天然真值。折扣、时域和平均奖励进一步规定跨时间的比较。

    交互、奖励与优化目标奖励假设与奖励设计平均奖励与差分价值

    目标规定要改善什么。奖励机制传递学习信号。状态规定决策时可以使用什么信息。三者需要分别定义。

  2. II

    状态构造与表征

    环境状态通常不可直接获得。智能体从观测、动作和奖励历史构造内部状态。状态更新、特征学习和参数学习是不同的计算过程。

    智能体状态与递归学习

    给定状态后，可以定义关于未来的预测。状态是否充分，取决于它需要支持哪些预测与决策。

  3. III

    预测与预测知识

    先固定策略，再学习回报预测。MC、TD 和资格迹提供不同的估计方法。GVF 进一步指定累积信号、延续条件和目标策略。预测不自动产生更好的行为。

    价值预测与资格迹通用价值函数与预测知识

    控制需要使用预测来改变策略。策略改变后，数据分布和需要预测的未来也会改变。

  4. IV

    控制与策略改善

    先区分固定策略的改善与完整学习器的生命期表现。持续控制中，动作同时改变世界、未来数据和后续学习。经典 GPI、动作价值和策略梯度提供局部工具；历史条件、可行比较器与资源限制决定这些工具能支持什么结论。

    持续控制与学习智能体比较深度价值学习策略梯度与 actor–critic最大熵控制

    这些控制方法都需要分配信用并选择更新尺度。持续交互要求学习过程也能适应。

  5. V

    时间信用分配

    多步回报从未来反馈构造学习目标。资格迹在反馈到来时更新过去相关的参数方向。递归网络还需要传播参数对内部状态的影响。信用分配可以用于预测，也可以用于控制。

    时间信用分配与资格迹

    信用分配规定反馈如何作用于过去。流式协议进一步限制数据保存与每步计算。

  6. VI

    流式学习与更新稳定性

    流式学习规定经验何时使用、能否重放。归一化和更新尺度控制处理数值稳定性。这些约束与机制不等于信用分配，也不要求使用元学习。

    流式更新与稳定性

    固定的更新规则可以依据当前数据调整尺度。元学习进一步用经验改善学习规则本身。

  7. VII

    元学习与学习规则的适应

    在线元梯度估计学习参数对后续表现的影响。跨任务元强化学习则利用任务分布，学习初始化、上下文推断或更新规则。两者的训练协议与评价对象需要分别定义。

    元学习与学习规则的适应

    有了学习机制，还需要规定可复用行为的目标、启动条件与终止规则。

  8. VIII

    子任务与时间抽象

    任务的总体目标与子任务目标需要区分。目标条件化策略描述一族控制问题。Option 则规定行为的启动条件、内部策略和终止规则。技能发现决定哪些行为进入可用集合。

    目标条件化与子任务构造Options 与技能发现

    能够执行一个行为，不等于知道它的后果。规划还需要这个行为的模型。

  9. IX

    模型学习与规划

    Dyna 用真实经验学习模型，再用模型更新价值。Option 模型预测随机时长行为的奖励和终点。规划决定在哪些状态、对哪些行为、使用多少次模型。

    Dyna 与模型学习转移模型与后果模型时间抽象与规划

    模型、状态、技能与策略都会变化。接下来需要研究这些变化怎样影响保留、适应与探索。

  10. X

    长期适应、保留与探索

    遗忘指已有能力下降。可塑性损失指学习新能力的速度下降。探索改变后续经验。这三类问题需要不同的对照实验，不能用同一个训练误差代替。

    知识保留与再适应可塑性与特征更新探索与经验选择

    在完整智能体中，这些机制共享经验与计算资源。它们的相互作用需要单独研究。

  11. XI

    持续学习的智能体架构

    状态为预测、策略和模型提供输入。子任务产生可学习的行为。模型支持规划。架构需要定义各模块的更新接口，也需要确定有限资源下的保留与替换规则。

    持续学习的智能体架构

    架构提出机制假设。实验检验实现、机制与长期收益。

  12. XII

    强化学习实验方法

    先定义要估计的量，再选择任务、基线与随机单位。开发数据用于选择配置。独立测试用于估计表现。持续学习还要区分在线收益、冻结诊断和恢复过程。

    实验设计、统计与算法测试

    实验设计贯穿全部章节。每学完一个更新规则，就可以运行小问题、提出反例并检验假设。

研究中的机制可以跨部分组合。例如，平均奖励 actor–critic 可以同时使用递归状态、资格迹和自适应步长；option 既可以帮助探索，也可以作为规划的动作单位。阅读顺序表示概念依赖，不表示这些方法彼此替代。

  1. 经验该变成哪些预测，才能在未来派上用场？

交互、奖励与优化目标

学习对象：奖励信号与跨时间的评价准则。

  1. 奖励 — 定义目标 → 回报

    规定累计时域、折扣和终止条件。改变这些条件可能改变策略排序。

  2. 策略目标 — 改变评价对象 → 学习器的在线表现

    冻结策略的价值不包含此前学习所付出的探索成本。

思考：奖励、回报、价值和学习器表现分别是什么量？

定义与推导实现与实验原文与作者代码

奖励假设与奖励设计

学习对象：偏好、奖励表示与学习信号。

  1. 结果偏好 — 检查表示条件 → 期望效用与逐步奖励

    彩票偏好与时间一致性决定哪些奖励分解成立。Markov 性依赖状态信息。

  2. 给定目标 — 改变学习信号或记忆结构 → 势函数塑形 / 奖励自动机

    塑形需处理边界；自动机把部分历史要求放进状态。

  3. 人的反馈 — 推断目标信息 → 偏好学习 / IRL / CIRL

    奖励模型仍有假设、不确定性与分布外失效。

思考：当前保证属于目标表示、策略排序、学习速度，还是安全性？

平均奖励与差分价值

学习对象：长期奖励率与相对价值。

  1. 折扣价值 — 改变目标 → 平均奖励与差分价值

    先定义稳态奖励率。再减去该奖励率，描述暂态收益。

  2. 差分 TD — 从预测到控制 → Differential Q / RVI

    评价固定策略与求最优策略使用不同的后继值。常数偏移需要单独处理。

  3. 平均奖励控制 — 扩展到近似连续控制 → RVI-SAC

    critic 参照、熵项和重置成本共同规定目标，不能与折扣中心化混同。

思考：平均奖励相同的两个策略，短期收益可以不同吗？

学习对象：当前反馈与过去预测、动作及参数的关系。

CQL 通过保守价值估计缓解数据外动作的过估计；IQL 避免训练时查询数据集外动作来学习价值；序列建模是另一种从轨迹提取策略的路线。转入在线阶段后，还需处理探索、数据混合和表示适应。

有 replay 不等于 offline；预训练后在线微调也不自动证明长生命期 CRL。

Meta-RL、快速适应与任务推断

RL² / MAML 风格优化 / 上下文推断

外层训练塑造跨任务的适应过程；内层可表现为参数更新或递归状态变化。它与终身更新能组合，但必须说明外层与内层哪些东西持续改变。

在固定元训练分布上快速适应，不保证面对持续新任务仍积累能力。

多智能体、伙伴适应与自博弈

独立学习 / 集中训练分散执行 / 自博弈

伙伴或对手也在学习，会使单个 agent 看到的经验分布变化。价值分解、critic 可用的信息和训练人口管理是不同设计位置；MARL 可与 PPO、actor–critic 和模型方法相交。

由其他 agent 更新造成的非平稳性，不等于显式任务切换；需区分队友泛化、对手适应与遗忘。

分布式与大规模数据收集

A3C / IMPALA / Ape-X / R2D2

多个 actor 与 learner 的速度不同，会产生策略滞后；IMPALA 的 V-trace 用于相应的 off-policy 校正。吞吐量、数据复用和更新延迟需要分别记录。

分布式 distributed 不是分布价值 distributional；训练更久、并行更多也不自动构成 CRL。

从组件学习到持续智能体

不同学习对象可以有不同的变化速度。有限计算和存储限制每次更新。长期回报、预测误差和新任务学习速度需要分别测量；并非所有模块都必须每步改变。

Alberta Plan 研究表征、预测、控制与规划的组合。Abel 等人从智能体生成关系讨论持续性的定义。Bowling 及合作者研究奖励表示条件与学习过程的评价。计算受限框架和非平稳框架又给出不同的比较条件。这些观点可以相互补充，但不能合并成一个已经统一的理论。
