    THE REINFORCEMENT LEARNING PROBLEM

    从理解智能到构建人工心智

    智能从何而来？人和许多其他动物都能从与世界的交互中学习。个体会根据过去的结果，调整对未来的预期和下一次的选择。实现目标既依靠身体能够做什么，也依靠怎样利用信息决定做什么。对于后一方面，McCarthy提出、Sutton阐释的定义是：智能是在世界中实现目标的能力中的计算部分。这里的目标，是所要达成或维持的结果；计算则包括感知、记忆、推断与选择等信息处理。

    感知提供信息，记忆让过去的经验参与现在的判断，预测与思考帮助个体权衡行动的后果。从功能与计算的角度看，心智是这些过程及其组织；智能则描述这种组织在实现目标时表现出的能力。学习使知识、判断和行为方式随经验改变，已经学到的东西因而能够用于以后的预测和行动。生物心智既有演化形成的基础，也在这样的学习中发展；人工系统能否同样从经验中发展智能？

    在强化学习的计算框架中，系统通过行动获得经验，依据行动后果的奖励反馈，学习怎样取得更好的长期结果。记忆、预测和规划为行动提供依据，行动产生的新经验又用来修正知识和行为。强化学习关心怎样利用这些改变，提高系统实现目标的能力，让智能在学习中发展。研究这些心智过程怎样在经验中形成和协作，是构建能够自主学习的人工心智的一条途径。我们希望这样的系统不仅能运用已有知识，还能不断形成新的能力，进而参与创造与设计。

    强化学习试图解决什么问题

    学习带来的改变怎样才算有益？这取决于所追求的目标。在强化学习中，我们把负责学习和选择行动的部分称为智能体，把与它交互的其余部分称为环境。智能体获得关于当前处境的信息，作出选择，再收到行动后果的观测与奖励。这些交互构成它能够利用的经验。奖励是评价实际结果的数值反馈，却通常不直接给出正确动作。智能体需要通过尝试，逐渐发现怎样行动才能取得更好的结果。

    困难在于，行动的后果往往不会立即显现。一个选择可能带来很高的眼前奖励，却使以后的处境变差。因此，评价学习的效果需要比较长期结果，并规定怎样汇总奖励：累加一段时间内的奖励，让较远的奖励权重更小，或比较长期单位时间的平均奖励。这些规则规定了不同的目标。在给定目标下，算法需要回答怎样利用有限经验学会更好的行为，记忆、预测与规划也要为此服务。

    设计者选择问题，并安排观测、动作、奖励与学习条件。三元图画出设计者怎样组织任务，以及可能在运行中提供哪些帮助；二元图则着重画出智能体与环境的交互，考察智能体怎样依据自身经验承担更多学习工作。二元交互并不是没有设计者，而是进一步追问，哪些原本由人完成的工作可以成为学习的一部分。

    持续强化学习的问题索引

    按问题查阅：从目标与预测到完整智能体

    智能体通过行动获得经验。学习改变它对未来的预测，也改变它的行为。以下按问题联系查找目标、状态、预测、控制、更新规则与规划。循序阅读时使用第三册正文目录；需要回查方法关系时使用本索引和算法谱系。

    第一遍的主线：整体问题 → 定义目标 → 设计奖励 → 评价策略 → 比较完整学习器 → 检验算法。

    尚未学过策略改善，可先读表格分册中的动态规划和采样控制。主线控制章进一步研究学习过程、历史条件与单次生命期比较。状态、信用分配、GVF 和元梯度按所选问题继续阅读。

    已有 DQN / PPO 经验：先明确目标、状态和数据权限。再进入对应研究分支。实验方法可以与任一章节配合阅读。

    1. I

      强化学习问题与目标

      从智能体与世界的持续交互出发，区分外部设计者的偏好、实际奖励和评价准则。奖励是假设与设计的对象，不是结果好坏的天然真值。折扣、时域和平均奖励进一步规定跨时间的比较。

      交互、奖励与优化目标奖励假设与奖励设计平均奖励与差分价值

      目标规定要改善什么。奖励机制传递学习信号。状态规定决策时可以使用什么信息。三者需要分别定义。

    2. II

      状态构造与表征

      环境状态通常不可直接获得。智能体从观测、动作和奖励历史构造内部状态。状态更新、特征学习和参数学习是不同的计算过程。

      智能体状态与递归学习

      给定状态后，可以定义关于未来的预测。状态是否充分，取决于它需要支持哪些预测与决策。

    3. III

      预测与预测知识

      先固定策略，再学习回报预测。MC、TD 和资格迹提供不同的估计方法。GVF 进一步指定累积信号、延续条件和目标策略。预测不自动产生更好的行为。

      价值预测与资格迹通用价值函数与预测知识

      控制需要使用预测来改变策略。策略改变后，数据分布和需要预测的未来也会改变。

    4. IV

      控制与策略改善

      先区分固定策略的改善与完整学习器的生命期表现。持续控制中，动作同时改变世界、未来数据和后续学习。经典 GPI、动作价值和策略梯度提供局部工具；历史条件、可行比较器与资源限制决定这些工具能支持什么结论。

      持续控制与学习智能体比较深度价值学习策略梯度与 actor–critic最大熵控制

      这些控制方法都需要分配信用并选择更新尺度。持续交互要求学习过程也能适应。

    5. V

      时间信用分配

      多步回报从未来反馈构造学习目标。资格迹在反馈到来时更新过去相关的参数方向。递归网络还需要传播参数对内部状态的影响。信用分配可以用于预测，也可以用于控制。

      时间信用分配与资格迹

      信用分配规定反馈如何作用于过去。流式协议进一步限制数据保存与每步计算。

    6. VI

      流式学习与更新稳定性

      流式学习规定经验何时使用、能否重放。归一化和更新尺度控制处理数值稳定性。这些约束与机制不等于信用分配，也不要求使用元学习。

      流式更新与稳定性

      固定的更新规则可以依据当前数据调整尺度。元学习进一步用经验改善学习规则本身。

    7. VII

      元学习与学习规则的适应

      在线元梯度估计学习参数对后续表现的影响。跨任务元强化学习则利用任务分布，学习初始化、上下文推断或更新规则。两者的训练协议与评价对象需要分别定义。

      元学习与学习规则的适应

      有了学习机制，还需要规定可复用行为的目标、启动条件与终止规则。

    8. VIII

      子任务与时间抽象

      任务的总体目标与子任务目标需要区分。目标条件化策略描述一族控制问题。Option 则规定行为的启动条件、内部策略和终止规则。技能发现决定哪些行为进入可用集合。

      目标条件化与子任务构造Options 与技能发现

      能够执行一个行为，不等于知道它的后果。规划还需要这个行为的模型。

    9. IX

      模型学习与规划

      Dyna 用真实经验学习模型，再用模型更新价值。Option 模型预测随机时长行为的奖励和终点。规划决定在哪些状态、对哪些行为、使用多少次模型。

      Dyna 与模型学习转移模型与后果模型时间抽象与规划

      模型、状态、技能与策略都会变化。接下来需要研究这些变化怎样影响保留、适应与探索。

    10. X

      长期适应、保留与探索

      遗忘指已有能力下降。可塑性损失指学习新能力的速度下降。探索改变后续经验。这三类问题需要不同的对照实验，不能用同一个训练误差代替。

      知识保留与再适应可塑性与特征更新探索与经验选择

      在完整智能体中，这些机制共享经验与计算资源。它们的相互作用需要单独研究。

    11. XI

      持续学习的智能体架构

      状态为预测、策略和模型提供输入。子任务产生可学习的行为。模型支持规划。架构需要定义各模块的更新接口，也需要确定有限资源下的保留与替换规则。

      持续学习的智能体架构

      架构提出机制假设。实验检验实现、机制与长期收益。

    12. XII

      强化学习实验方法

      先定义要估计的量，再选择任务、基线与随机单位。开发数据用于选择配置。独立测试用于估计表现。持续学习还要区分在线收益、冻结诊断和恢复过程。

      实验设计、统计与算法测试

      实验设计贯穿全部章节。每学完一个更新规则，就可以运行小问题、提出反例并检验假设。

    研究中的机制可以跨部分组合。例如，平均奖励 actor–critic 可以同时使用递归状态、资格迹和自适应步长；option 既可以帮助探索，也可以作为规划的动作单位。按问题分组便于比较这些联系；所需先修知识见各章开头。

    问题设定、知识表示和学习机制是三种不同的分类依据。目标与交互协议定义问题；状态、预测、技能和模型描述学习对象；保留、可塑性与元学习则改变学习过程。以下索引用于定位具体研究问题，各类方法可以组合。

    ① 设定长期目标 · 变化来源 · 信息
    重置 · 回放 · 任务边界
    ② 失败跟踪误差 · 干扰 · 可塑性
    状态不足 · 探索不足
    ③ 干预改学习对象或更新机制
    写清接口、假设与预算
    ④ 证据解析小例 → 受控消融

    先把问题说清

    1. 一生的“学得好”到底指什么？

      终局测试很高，但适应时损失巨大，或者依赖免费重置。

    诊断为什么学不好

    1. 规律变了，怎样及时发现并改正？

      旧估计非常稳定，却迟迟跟不上新奖励或新动力学。

      读：先理解估计器如何跟踪 →
    2. 当前画面不够，应该记住什么？

      相同观测需要不同动作；更大的前馈网络仍做错。

      读：状态与递归信用 →
    3. 新知识怎样不破坏仍有用的旧知识？

      学完 B 后，在相同协议下重新测 A，A 的表现下降。

      读：保留机制与代价 →
    4. 训练久了，为什么新东西越来越难学？

      老网络获得相同新数据和预算，却比合适的 fresh 参照学得慢。

      读：可塑性机制与诊断 →
    5. 每步预算很小，怎样可靠地分配信用？

      实时更新发散、梯度延迟太长，或者一个环境步用了大量隐含回放。

      读：Streaming 与 traces →

    把经验变成可复用能力

    1. 经验该变成哪些预测，才能在未来派上用场？

      奖励之外的规律反复重学；辅助损失下降却没有改善决策。

      读：GVF 从定义到学习器 →
    2. 怎样形成可复用的目标与长行为？

      每个任务都从原始动作重新探索，技能库却越积越多而用不上。

      读：目标与子任务 →
    3. 怎样用后果模型减少真实试错？

      模型内预测很好，现实行为却错误；规则变后越规划越自信。

      读：模型的对象与递推 →

    让学习持续，并检验系统

    1. 接下来学什么、去哪探索，还能否安全回来？

      永远遇不到新证据，或者探索一次就失去后续交互与学习的机会。

      读：探索与内在信号 →
    2. 能不能让学习过程本身越用越合适？

      每次换环境都重新调步长，或者短期学得快却长期不稳定。

      读：元学习的三种协议 →
    3. 把模块接起来，怎样证明真的在持续积累？

      每个模块单测正常，整机却没有长期收益，结论只剩一条平均曲线。

      读：完整智能体与更新时序 →

    I强化学习问题与目标什么结果算更好？

    交互、奖励与优化目标

    学习对象：奖励信号与跨时间的评价准则。

    1. 奖励 — 定义目标 → 回报

      规定累计时域、折扣和终止条件。改变这些条件可能改变策略排序。

    2. 策略目标 — 改变评价对象 → 学习器的在线表现

      冻结策略的价值不包含此前学习所付出的探索成本。

    思考：奖励、回报、价值和学习器表现分别是什么量？

    奖励假设与奖励设计

    学习对象：偏好、奖励表示与学习信号。

    1. 结果偏好 — 检查表示条件 → 期望效用与逐步奖励

      彩票偏好与时间一致性决定哪些奖励分解成立。Markov 性依赖状态信息。

    2. 给定目标 — 改变学习信号或记忆结构 → 势函数塑形 / 奖励自动机

      塑形需处理边界；自动机把部分历史要求放进状态。

    3. 人的反馈 — 推断目标信息 → 偏好学习 / IRL / CIRL

      奖励模型仍有假设、不确定性与分布外失效。

    思考：当前保证属于目标表示、策略排序、学习速度，还是安全性？

    平均奖励与差分价值

    学习对象：长期奖励率与相对价值。

    1. 折扣价值 — 改变目标 → 平均奖励与差分价值

      先定义稳态奖励率。再减去该奖励率，描述暂态收益。

    2. 差分 TD — 从预测到控制 → Differential Q / RVI

      评价固定策略与求最优策略使用不同的后继值。常数偏移需要单独处理。

    3. 平均奖励控制 — 扩展到近似连续控制 → RVI-SAC

      critic 参照、熵项和重置成本共同规定目标，不能与折扣中心化混同。

    思考：平均奖励相同的两个策略，短期收益可以不同吗？

    II状态构造与表征智能体需要从历史中保留什么信息？

    智能体状态与递归学习

    学习对象：从历史构造的决策信息。

    1. 历史 — 构造状态 → belief / 递归状态

      已知模型可更新信念分布。未知模型可学习历史摘要。两者的充分性条件不同。

    2. 递归计算 — 分配历史信用 → BPTT / RTRL / RTU

      这些方法计算或近似参数对状态的影响。它们不是新的任务目标。

    3. 分段递归训练 — 改变信用计算协议 → Memoroids / 完整序列与 RTRL

      并行 scan 利用保存的序列。实时敏感度利用递推状态；训练内存与每步预算不同。

    思考：内部状态变化和模型参数学习如何区分？

    III预测与预测知识在指定行为下，未来会发生什么？

    价值预测与资格迹

    学习对象：给定策略下的期望回报。

    1. 完整回报 MC — 改变估计方法 → 一步 TD

      TD 用当前预测替代尚未获得的未来回报。预测对象仍然不变。

    2. 一步 TD — 扩展信用时域 → n-step / TD(λ) / true-online

      多步目标与资格迹关联。在线参数变化决定前后向等价关系。

    思考：一次 TD 误差小，是否说明价值误差小？

    定义与推导实现与实验原文与作者代码

    通用价值函数与预测知识

    学习对象：行为条件下的累积信号预测。

    1. 奖励价值 — 推广问题规格 → GVF

      累计信号不必是奖励。目标策略与延续条件仍需明确。

    2. 单个预测器 — 组织问题与选择学习器 → Horde；GTD / ETD

      Horde 组织多个问题。GTD 与 ETD 处理特定离策略函数逼近问题。这是两个层次。

    3. 有限 cumulant 向量 — 扩大可查询的预测知识 → SF / FB / successor measure

      查询读出依赖占用约定、奖励特征和行为覆盖。

    4. 未来占用 — 分开生成和读出接口 → SF² 的生成式预测与控制特征

      向量场对条件特征线性，不保证下游价值线性。

    思考：换累积信号与换更新算法，哪一种改变被预测的真值？

    IV控制与策略改善智能体怎样选择动作并改善行为？

    持续控制与学习智能体比较

    学习对象：包括记忆与学习规则的持续行动过程。

    1. 固定 MDP 的策略评价与 GPI — 扩大评价对象 → 历史条件的完整学习器价值

      未来参数更新、信息获取与不可逆后果影响生命期表现。

    2. 最终策略分数 — 改变比较条件 → 生命期效用 / 可行偏离比较

      声明历史、时间、资源与比较器权限，不能直接对照不可实现 oracle。

    3. 自然终止与外部重置 — 将恢复纳入时间轴 → Continuing / reset-free / 可恢复控制

      重置后的状态、奖励和耗时是控制过程的一部分。

    思考：当前值函数评价冻结策略，还是包含后续学习？

    深度价值学习

    学习对象：参数化动作价值。

    1. 表格 Q-learning — 改变函数表示 → DQN

      共享参数产生泛化，也会引入干扰。回放和目标网络分别调整数据与目标。

    2. DQN — 分开选择与评估 → Double DQN

      在线估计选动作。另一估计评价该动作。两者仍可能相关。

    思考：误差来自目标、网络梯度，还是经验覆盖？

    策略梯度与 actor–critic

    学习对象：参数化行为策略。

    1. REINFORCE — 改变梯度估计 → baseline / actor–critic

      baseline 可降低方差。学得的 critic 提供价值或优势估计。

    2. 策略梯度 — 组合估计与优化 → GAE + PPO

      GAE 构造优势估计。PPO 优化裁剪代理目标。两者不是同一个改动。

    学习对象：带熵项的控制目标。

    V时间信用分配当前反馈应当更新过去哪些预测与决策？

    时间信用分配与资格迹

    学习对象：当前反馈与过去预测、动作及参数的关系。

    1. n-step / λ-return — 由前向目标到后向更新 → TD(λ) / true-online TD(λ)

      资格迹累积过去的梯度方向。冻结参数与在线参数下的等价关系不同。

    2. 预测信用 — 用于控制 → SARSA(λ) / actor traces

      行为策略和目标策略决定迹的含义。离策略更新不能直接套用同策略推导。

    3. 递归状态 — 传播状态敏感度 → BPTT / RTRL

      参数还通过过去状态影响当前输出。这条导数路径不同于奖励传播的时间尺度。

    4. 多步 TD 误差 — 区分传播与策略校正 → Tree-backup / Retrace / V-trace

      传播系数决定历史长度。误差中的比率决定目标；两者的截断不能互换。

    5. 采样的资格迹 — 改变估计对象 → Expected Traces / 梯度资格迹

      条件期望迹减少部分路径方差；梯度迹服务于明确的误差目标。两者使用不同假设。

    思考：资格迹、循环状态和元敏感度分别记住了什么？

    VI流式学习与更新稳定性在有限内存和逐步计算预算下，怎样执行学习？

    流式更新与稳定性

    学习对象：有限数据存储和每步预算下的参数更新。

    1. 逐步 TD / actor–critic — 控制更新尺度 → Stream-X / ObGD / StreamingOptimizer

      归一化与过冲控制针对单步更新。不同论文版本的优化器不能混用。

    2. 参数空间更新 — 约束局部输出变化 → Intentional updates

      利用输出对参数的导数选择尺度。这不是沿学习历史优化外层目标。

    思考：无回放、每步更新和无重置分别限制什么？

    VII元学习与学习规则的适应怎样根据学习效果调整学习过程？

    元学习与学习规则的适应

    学习对象：步长、学习目标、初始化或更新规则。

    1. 更新映射的链式法则 — 在线近似敏感度 → IDBD / TIDBD / Metatrace

      各方法保存不同的历史导数，并采用不同的近似。

    2. 可学习步长 — 扩展适应对象 → Meta-gradient RL

      用后续评价调整折扣或回报构造。内层学习目标与外层评价目标需要区分。

    3. 跨任务经验 — 改变适应协议 → MAML / RL² / PEARL / learned rules

      初始化、上下文和更新规则依赖不同的训练与测试协议。

    4. 在线敏感度更新 — 区分局部适应和外部搜索 → TRAC / 算法元学习比较

      在线调节尺度不等于通过未来回报做元梯度；元训练计算必须报告。

    思考：方法改变的是当前状态、网络参数，还是学习规则？

    VIII子任务与时间抽象哪些可复用行为值得学习？

    目标条件化与子任务构造

    2. 给定目标集合 — 学习选择或构造 → HIQL / MaestroMotif / 子任务构造

      层次选择已有目标与生成新目标是不同的问题。子任务用途由后续行为检验。

    Options 与技能发现

    学习对象：可变时长的闭环行为。

    1. 原始动作 — 扩展决策单位 → Options / SMDP / Option-Critic

      组合训练不足与缺少必要基础必须分开检验。

    IX模型学习与规划怎样用学得的后果模型改善决策？

    Dyna 与模型学习

    学习对象：真实经验与模型生成的备份。

    1. 直接 RL + 模型学习 — 组合学习与规划 → Dyna

      同一条真实经验更新价值和模型。模型提供额外备份。

    2. 均匀模型采样 — 分配规划计算 → Prioritized sweeping / search control

      优先级改变备份顺序。模型失效仍需新经验纠正。

    离线数据、多智能体和任务分布属于独立的设定维度。它们可以与价值学习、策略学习或模型学习组合。

    离线 RL 与 offline-to-online

    行为约束 / CQL / IQL / Decision Transformer

    CQL 通过保守价值估计缓解数据外动作的过估计；IQL 避免训练时查询数据集外动作来学习价值；序列建模是另一种从轨迹提取策略的路线。转入在线阶段后，还需处理探索、数据混合和表示适应。

    有 replay 不等于 offline；预训练后在线微调也不自动证明长生命期 CRL。

    Levine 等 · Offline RL 教程CQLIQLDecision Transformer
    Meta-RL、快速适应与任务推断

    RL² / MAML 风格优化 / 上下文推断

    外层训练塑造跨任务的适应过程；内层可表现为参数更新或递归状态变化。它与终身更新能组合，但必须说明外层与内层哪些东西持续改变。

    在固定元训练分布上快速适应，不保证面对持续新任务仍积累能力。

    Duan 等 · RL²Meta-RL 与课程章节
    多智能体、伙伴适应与自博弈

    独立学习 / 集中训练分散执行 / 自博弈

    伙伴或对手也在学习，会使单个 agent 看到的经验分布变化。价值分解、critic 可用的信息和训练人口管理是不同设计位置；MARL 可与 PPO、actor–critic 和模型方法相交。

    由其他 agent 更新造成的非平稳性，不等于显式任务切换；需区分队友泛化、对手适应与遗忘。

    分布式与大规模数据收集

    A3C / IMPALA / Ape-X / R2D2

    多个 actor 与 learner 的速度不同，会产生策略滞后；IMPALA 的 V-trace 用于相应的 off-policy 校正。吞吐量、数据复用和更新延迟需要分别记录。

    分布式 distributed 不是分布价值 distributional；训练更久、并行更多也不自动构成 CRL。

    Espeholt 等 · IMPALA递归 replay 分支

    从组件学习到持续智能体

    不同学习对象可以有不同的变化速度。有限计算和存储限制每次更新。长期回报、预测误差和新任务学习速度需要分别测量；并非所有模块都必须每步改变。

    Alberta Plan 研究表征、预测、控制与规划的组合。Abel 等人从智能体生成关系讨论持续性的定义。Bowling 及合作者研究奖励表示条件与学习过程的评价。计算受限框架和非平稳框架又给出不同的比较条件。这些观点可以相互补充，但不能合并成一个已经统一的理论。
