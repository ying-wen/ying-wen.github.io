YOUR FIRST COMPLETE CRL EXPERIMENT

从一条更新式，到一页实验结论

问题只有一个：奖励规律变了以后，旧经验会不会让学习器反应太慢？先完成这个约 60–90 分钟的小实验，再接到更复杂的 CRL。

你需要：知道动作、奖励、样本平均；能在终端运行 Python 3。不需要 GPU、PyTorch 或先读论文。

你会得到：一份逐 seed 的 CSV、一份自动生成的图表报告，以及一个只改变一项因素的对照实验。

问题公式与代码运行看图继续研究

1. 先写下你要研究什么

每步在 A、B 两个动作中选一个，得到 0 或 1 的奖励。前 2,000 步，A 获得 1 的概率为 0.8，B 为 0.2；后 2,000 步交换。学习器不知道切换时刻，只能看到自己选中动作的奖励，价值和计数始终保留。

比较两种估计规则：每次等权累计全部历史，或始终给新奖励一个固定权重。动作选择规则、交互次数和随机种子都保持一致。

运行前先预测：哪种方法在变化后恢复更快？哪种方法的估值更平滑？两问的答案不一定指向同一个方法。

2. 把符号、公式和代码对齐

Q(a) 估计动作 a 的奖励均值，N(a) 是它被选择的次数；R 是这一次收到的奖励。下式只更新刚选中的动作，未选中的 Q 不动。

N(a)←N(a)+1,Q(a)←Q(a)+η [R−Q(a)]N(a)\leftarrow N(a)+1,\qquad Q(a)\leftarrow Q(a)+\eta\,[R-Q(a)]N(a)←N(a)+1,Q(a)←Q(a)+η[R−Q(a)]
横向滚动查看完整公式 →
η={1/N(a),样本平均α,常数步长\eta=\begin{cases}1/N(a),&\text{样本平均}\\\alpha,&\text{常数步长}\end{cases}η={1/N(a),α,​样本平均常数步长​
横向滚动查看完整公式 →

当 α=0.1，Q(A)=0.8 而这次奖励为 0，新的 Q(A) 为 0.72。只有把这一步算清楚，后面的曲线才不会变成黑箱。第二课解释为什么这等价于指数衰减的历史权重。

# 两个方法都用 ε-greedy 选择动作：
# 概率 ε 随机选 A/B，否则选 Q 最大的动作；平局随机打破。
action = select_action(q, epsilon)
reward = observe_reward(action)
n[action] += 1
rate = 1 / n[action] if method == 'sample_mean' else alpha
q[action] += rate * (reward - q[action])

这段是阅读伪代码；下载脚本中的 bandit() 是完整实现。依次找到 action（决策）、probs（环境）、rate（学习规则）、metrics（记录）。切换条件只在环境一侧，学习器不会收到通知。

python3 examples/crl_labs.py bandit --seeds 20 --steps 4000 --alpha 0.1 --epsilon 0.1 --out bandit-a01.csv

双击生成的 bandit-a01.html 即可看图，无需绘图库或本地服务器。CSV 保存 seed、配置、窗口长度、奖励、选择 B 的比例和两个 Q 值；报告中可以展开每个 seed 的分段摘要。

完成检查：CSV 有 6,400 行数据（加 1 行表头）；报告有 4 张图和分段奖励表。默认每 100 步记录一个窗口，两个方法 × 20 seeds × 40 窗口 × 4 指标。
为什么浏览器里的曲线不完全一样？

浏览器演示使用 2,000 步、50 步窗口和不同的伪随机生成器；Python 默认 4,000 步、100 步窗口。它们演示同一机制，但不是逐点相同的实验。跨方法使用同一组外部随机数有助于对照，两个方法仍可能选择不同动作、得到不同奖励。

4. 依次看现象、行为、估计

看哪张图它回答什么不能单独回答什么
窗口奖励变化后实际收益怎样下降和恢复？究竟是没探索，还是更新慢？
选择 B 的比例是否逐渐放弃过去更好的 A？B 的估值为何改变？
Q(A)、Q(B)估值排序和波动如何影响动作？深度网络有没有失去学习能力？

报告粗线是跨 seed 均值，浅线是各次运行。分段表先在每个 seed 内按真实窗口长度求平均，再跨 seed 汇总；± 是运行间的样本标准差，不是置信区间。

思考：选择 B 的比例为什么通常不是 100%？

ε=0.1 时，每步有 10% 概率随机选择；即使 B 的估值一直更高，仍有约 5% 的步数随机选 A。有限样本还会波动。如果估值排序也会反转，B 比例可能更低。

5. 只改变一个因素

保留 ε、steps 和 seeds，只将 α 改成 0.5。输出使用新名字，不覆盖第一份结果。

在 continual-rl-tutorial 仓库根目录运行。

python3 examples/crl_labs.py bandit --seeds 20 --steps 4000 --alpha 0.5 --epsilon 0.1 --out bandit-a05.csv
python3 examples/analyze_crl.py bandit-a05.csv --out bandit-a05.html

两个报告并排看：样本平均的结果应完全一致，因为它不用 α；常数步长的恢复与波动可能变化。若没有这个不变性，先检查你是否改了其他配置或代码。

进一步练习与提示

① 将 ε 改为 0：这只取消随机探索，奖励噪声或平局仍可能导致动作切换，不能笼统说必定永远选 A。② 使用 --switch 3000：观察生命期更长时样本平均的适应；同时报告变化后只剩 1,000 步这一条件。③ 选定设置后再用更多独立 seeds 检查，不挑好看的单次运行。

6. 写出第一张实验结论卡

问题：固定奖励规则突然反转后，哪种估计规则更容易适应？
协议：4,000 步；2,000 步后反转；无通知、无清零；ε=0.1。
只改一项：常数步长 α=0.1 → 0.5。
观察：填写变化后起始段、剩余段的均值与 SD；解释 Q 值和动作比例。
其他解释：探索不足？估值噪声？结果由少数 seed 主导？
结论边界：两臂奖励跟踪实验；不代表深度可塑性或所有 CRL 问题。
下一步：明确一个尚未排除的解释，只增加一项对照。

下一步：从教学实验走向研究

你现在能做的是识别跟踪与探索的区别，而不是已经解决 CRL。接下来只选一个新困难：

  1. 增加函数逼近：旧任务退步和新任务难学分别怎么测？
  2. 隐藏决定奖励的线索：是学习率问题，还是缺少历史？
  3. 从 bandit 到 TD：带自举和时间信用分配的更新还稳定吗？

进入官方深度 RL 代码前，先读 CleanRL 导读；设计论文实验前，读 Adam White 的实验讲座导读。
