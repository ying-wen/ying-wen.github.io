    Arsalan Sharifnassab｜更新几何、步长适应与流式学习

    机构官方成员名录、作者主页与原始研究来源

    在教材主线中的位置

    价值预测与时间差分学习流式强化学习：交互协议与更新稳定性学习规则的适应：在线元梯度与跨任务元学习实验设计：从更新正确到持续学习证据通用价值函数与预测知识

    沿章节进入问题设定、推导与实现。实验条件和研究问题在每章末对应列出。

    直接查看个人论文、课程、讲座与随笔（27 项） ↓

    参数空间中的固定步长并不固定函数输出的变化。需要区分预条件更新方向、即时输出尺度控制和利用后续损失适应元参数；三者可以组合，但估计对象和证据不同。

    人物与研究问题

    Sharifnassab 的训练横跨数学、电气工程与动态系统，早期研究包括调度、扰动敏感性及分布式学习。进入 Sutton 研究组并加入 Openmind 后，他聚焦学习器本身的效率：价值目标的条件数、步长怎样适应、单样本更新怎样产生可控的函数变化。

    Openmind：Research Fellow（研究员） · 机构名录 · 个人主页

    研究如何发展

    RANS 从梯度式价值估计为何缓慢出发，分析 Bellman 误差目标的病态条件数，以低复杂度近似处理更新方向。这一线把稳定性与效率看作不同问题。

    Step-size Optimization、SwiftTD 和 MetaOptimize 转向学习规则的时间依赖：步长会改变未来参数、误差与后续学习，元梯度应追踪这种影响；低成本近似决定方法能否用于持续更新。

    Intentional Updates 先规定希望减少多少 TD 误差、允许策略变化多少，再求近似实现该意图的步长。个人主页还列出语言模型对齐与基础模型兴趣，但本教材主线选择其价值估计和在线优化工作。

    代表工作与读法

    • Toward Efficient Gradient-Based Value Estimation（ICML，2023）：分析 RANS、病态条件数与近似 Gauss–Newton 更新，核对所需采样假设。
    • MetaOptimize（ICML，2025）：从未来损失目标推到元梯度，再比较低成本近似；用正式更新版本。
    • Intentional Updates for Streaming RL（ICML，2026）：先写 TD 与策略各自的 intended outcome，再讨论实际更新的近似误差。

    结论边界

    无须为每个任务重新搜索某些步长，不代表方法没有其他元参数。局部线性或二阶近似、资格迹和元梯度的截断都可能影响结果。个人发表目录保留部分早期投稿标注，具体版本与发表状态应看论文原始页面。

    带回教材的思考题

    如果两个学习器具有相同的即时输出变化，一个使用元梯度、另一个仅做归一化，怎样设计漂移预测实验，识别对未来学习影响的适应是否产生额外收益？

    • 价值预测与资格迹：比较 Bellman 目标与更新几何。
    • 流式更新与稳定性：从预期函数变化理解单样本稳定化。
    • 元学习与学习规则的适应：追踪学习规则对未来误差的影响。
    • 实验设计、统计与算法测试：拆分预条件、尺度控制与元学习的作用。
