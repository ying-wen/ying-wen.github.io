    人物与研究问题

    Martin 是 Openmind Fellow、University of Alberta 兼职教授。他借助强化学习、认知研究和哲学给人工心智的核心现象以明确表述，研究经历也涉及机器人、航空与芯片设计。其近期问题是计算与能动性的关系：智能体能否利用环境完成部分计算，计算方式又怎样改变可获得的经验？

    Openmind：Research Fellow（研究员） · 机构名录 · 个人主页

    研究如何发展

    从机器人与不确定性问题，到价值分布和 Atari 中的干扰诊断，再到与 Modayil 共同研究在线函数逼近结构的适应，Martin 持续关注表示方式如何改变学习行为。

    Settling the Reward Hypothesis 刻画目标可用累积标量奖励表达所需的条件；Meta-Gradient Search Control 则学习 Dyna 应优先查询哪些状态，使有限规划计算更有用。前者约束问题表述，后者调整解题过程。

    Artifacts as Memory Beyond the Agent Boundary 将环境中留下的痕迹纳入记忆分析：某些可观察的 artifacts 能减少显式表示历史所需的信息。这为部分可观测性带来一个新接口——改变环境与压缩内部历史可以相互替代。

    代表工作与读法

    • Settling the Reward Hypothesis（ICML，2023）：与 Bowling、Abel、Dabney 合作；逐项检查可表达性的假设。
    • Meta-Gradient Search Control（2024）：区分模型学习、规划备份和状态查询概率的元更新。
    • Artifacts as Memory Beyond the Agent Boundary（2026，预印本）：从 artifacts 的信息条件出发，再读空间路径实验。

    结论边界

    奖励假设的结果有明确的表示条件，并非证明任意欲望都可由任意即时奖励表达。外部记忆论文目前是 2026 预印本，展示特定条件与实验中的记忆节约；它不意味着环境痕迹总可靠或无需内部状态。

    带回教材的思考题

    让智能体能留下外部标记后，怎样比较内部记忆、环境存储和行动成本？若标记会消失或被其他智能体修改，原来的记忆优势还成立吗？

    • 奖励假设与奖励设计：检验目标能被奖励表达的条件。
    • 智能体状态与递归学习：研究内部状态与外部痕迹的边界。
    • 时间抽象与规划：分配有限的模型查询与备份。
    • 元学习与学习规则的适应：通过后续学习效果适应规划采样。
    • 持续学习的智能体架构：把身体、环境和计算纳入系统边界。
