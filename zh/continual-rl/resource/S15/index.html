    Csaba Szepesvári｜统计效率和算法边界

    在教材主线中的位置

    价值预测与时间差分学习持续控制：比较策略与学习智能体规划：把模型中的经验转成更好的决策持续探索：新奇、不确定性、学习进展与恢复实验设计：从更新正确到持续学习证据时间信用分配：从资格迹到深度梯度学习

    沿章节进入问题设定、推导与实现。实验条件和研究问题在每章末对应列出。

    直接查看个人论文、课程、讲座与随笔（5 项） ↓

    级别：方法支柱 · 地域：加拿大／英国合作 · 模块：M02 M07 M18

    脉络： RL 算法理论、近似动态规划→bandit／探索与有限样本分析→表示及决策的统计复杂度。对 CRL 的贡献不是某一个“终身算法”，而是让比较对象、样本效率和假设说得清楚。先读算法讲义，再把变化预算、覆盖和函数类复杂度接入具体问题。作者主页 · RL 讲义

    从个人研究脉络继续学习

    Szepesvári 的脉络不是围绕单个“终身学习算法”，而是围绕序贯决策的效率与边界：从动态规划、函数逼近和随机逼近，到 bandit、探索，再到表示、模型失配以及统计和计算复杂度。不同阶段反复追问的都是：什么信息足以支持一个可靠的决策？

    与 Kocsis 的 UCT 工作把 bandit 的探索原则引入模拟规划；它依赖可以查询的生成模型。Algorithms for Reinforcement Learning 短教材和后续 RL Theory 课程进一步区分规划、批式学习与在线交互，使读者能看出看似相同的 Bellman 更新为何拥有不同保证。

    与 Lattimore 的 Bandit Algorithms 系统整理随机、对抗与结构化反馈问题。对 CRL 的直接方法价值在于明确比较器、覆盖、环境变化与函数类的条件，而不是把“遗憾小”当作无条件适应任何变化的同义词。

    个人网站提供按主题筛选的发表表、完整教材入口、公开课程及讲座；讲座包括模型失配、规划和对 RL 常见误解的讨论。配套 Bandit Algorithms 网站由作者书目与授课页链接，教材 PDF 则可直接从合作者网站读取。

    论文之外：课程、讲座、随笔与研究入口

    • Algorithms for Reinforcement Learning

      2010 年短教材，作者提供更新版 PDF 与勘误入口；先读问题分类，再读每类算法的条件与局限。

    • RL Theory：讲义、讲课和讨论录像

      从规划复杂度进入批式和在线 RL；课程网站同时保留历年内容，不将站点更新日期当作每段录像的授课日期。

    • Bandit Algorithms 作者免费版

      与 Tor Lattimore 合著。将 UCB、Exp3 及上下界放在各自反馈和比较器定义下学习。

    • 讲座索引：模型失配、规划与 RL 误解

      2020 年系列报告附作者讲义及录像入口；可用来检查“表达力强”与“统计可学”之间的缺口。

    • Bandit Algorithms 配套网页入口

      作者书目页链接配套网站 banditalgs.com；以可直接取得的教材为主线，不把配套帖子当作额外实验证据。

    • UCT 原始全文

      直接阅读 PDF 的生成模型假设和树中采样机制；规划模拟数与真实交互数要分别统计。

    带回教材的问题

    如果一个定理使用生成模型、固定函数类和固定 MDP，删掉其中一项后，究竟是哪一步论证先失效？需要新的观测权限、结构条件，还是新的评价量？

    • 价值预测与资格迹：把表格 TD、函数逼近与随机逼近保证的条件逐一列出。
    • 持续控制与学习智能体比较：固定问题中的策略优化率不能代替整个持续学习器的生命期评价。
    • 探索与经验选择：用 bandit 上下界理解反馈不足和比较器选择，再进入状态会随动作改变的 RL。
    • 时间抽象与规划：区分可查询模型中的模拟效率、模型误差和真实交互效率。
    • 实验设计、统计与算法测试：让统计效率结论与实际实验的数据访问、资源预算保持一致。

    读完留下一张问题卡

    • 它解决哪一种失败？什么假设下有效？
    • 有没有提供额外历史、task ID、重置或回放权限？
    • 最小对照是什么？源码的哪一段决定结论？
    • 把它接到长期生命史，哪里仍可能失效？
