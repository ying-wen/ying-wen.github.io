温颖 Ying Wen｜相互影响、递归推理与合作决策

在教材主线中的位置

持续学习的智能体架构智能体状态与递归学习元学习与学习规则的适应

沿章节进入问题设定、推导与实现。实验条件和研究问题在每章末对应列出。

级别：多智能体方法支柱与持续交叉 · 地域：中国（上海交通大学） · 模块：M09 M16 M17

核心问题： 其他 agent 会学习、推理并对自己的行动作出反应，怎样把这种相互影响写进决策过程？其与 CRL 的连接主要在伙伴／对手变化、内部推断状态与经验复用，而非把所有 MARL 都当成终身学习。交大官方介绍 · 作者主页

第一条线：从预测他人行为到推断相互反应。 PR²（ICLR 2019；Ying Wen、Yaodong Yang、Rui Luo、Jun Wang、Wei Pan）把对手对自己行为的条件反应纳入概率递归推理。阅读重点是条件策略、变分近似和最优反应的关系；区分“预测对手下一动作”与“预测对手如何回应我的选择”。它给出指定博弈设定中的分析与实验，不保证任意学习对手下都收敛。PR² 原文

第二条线：有限理性与多层推理。 GR²（IJCAI 2020 正式版本作者为 Ying Wen、Yaodong Yang、Jun Wang）将推理层级作为建模对象。可与 PR² 对读：增加的是推理结构与响应模型，而不只是网络大小。层级升高伴随什么计算代价？对手不符合假定的层级时会怎样？GR² 正式论文、BibTeX 与短视频入口

第三条线：把合作决策组织成序列。 MAT（NeurIPS 2022）由温睦宁、Jakub Grudzien Kuba、Runji Lin、张伟楠、温颖、汪军、杨耀东共同完成，将合作多智能体的联合行动构造与序列模型连接。它与 PR²／GR² 是不同方法支线，不能混写成同一算法的三个版本；尤其要分清“按 agent 顺序生成动作”和“沿真实时间做长期记忆”。MAT 原文 · 官方实现

学习与研究入口： 入门先补 Markov game、条件概率和 actor–critic，再用双人矩阵博弈追踪一次条件反应更新；有 RL 背景者对比独立学习、普通 opponent model 与递归模型，控制观测权限和总计算，再把伙伴变化加入协议。MAT 的实现可用来观察联合动作生成与训练的信息流，未在本轮安装训练。会议短视频仅核验入口，未作完整观看摘要。

尚需检验的 CRL 问题： 对手反复出现时，旧反应知识能否保留并校正？增加推理深度得到的是当次搜索收益，还是持久可迁移知识？固定记忆和计算后，在线更新是否仍比检索旧策略或重新规划有效？这些是研究切入点，不是上述论文已经全部解决的结论。
