Streaming Reinforcement Learning under Partial Observability with Real-Time Recurrent Learning

2026-07-07 · v2 预印本

在教材主线中的位置

时间信用分配与资格迹智能体状态与递归学习通用价值函数与预测知识价值预测与资格迹策略梯度与 actor–critic

沿章节进入问题设定、推导与实现。实验条件和研究问题在每章末对应列出。

为什么读

Farr、Reddi、D’Eramo、Peters 把实时递归更新接到部分可观测 streaming 控制。

怎样学

先理解 RTU 的结构限制，再比较 MemoryChain 与部分观测连续控制。

结论边界

高效精确梯度依赖所选结构，不是任意 RNN 的通用线性复杂度保证。
