课程与讲座 · 核心材料导读

David Abel — Where is Learning?

在教材主线中的位置

价值预测与资格迹持续控制与学习智能体比较深度价值学习策略梯度与 actor–critic最大熵控制

沿章节进入问题设定、推导与实现。实验条件和研究问题在每章末对应列出。

什么时候读：先完成第 1、4 课，知道“观测、内部状态、参数”的区别；不需要先掌握形式化 agent 理论。

这次只解决一件事：这场报告适合在见过具体例子后，用来检查自己把“学习”限定得是否过窄。它不是入门 RL 的第一课。

先带着这个例子

导航程序的网络权重一直不变，但它把新遇到的封路写进持久地图，下次出发会换路线。另一个程序每步刷新相机图像，却不留下任何跨经历的信息。两者都有“状态变化”，但保留了什么、影响哪些未来行为并不相同。

按这个顺序读，不用一遍读完

  1. 观看前：先给自己的例子下定义

    写出你认为学习发生在哪里：权重、地图、优化器，还是整个 agent。暂时不用选唯一答案。

  2. 观看时：围绕一个问题做笔记

    沿作者的论证检查“学习器的边界如何选择”。把听到的主张和你自己的延伸例子分列，不以记满术语为目标。

  3. 看完后：再读配套形式化论文

    进入 A Definition of Continual Reinforcement Learning，先抓 agent、环境与持续学习的问题关系，再决定是否读证明。不要把视频与配套论文当作逐句相同的材料。

读懂核心思路

在常见深度 RL 实现里，梯度更新是学习的重要机制，但它不是理解所有 agent 的唯一尺度。工作记忆帮助当前决策，持久更新可能改变以后如何决策或学习。分析一个方法时，先列出保留的状态、更新时间、清空条件以及对未来行为的作用，再讨论它是否满足某个形式化学习定义。

把理解变成一次检查

一个固定权重的 agent，在测试时写入可跨任务保留的记忆。你要检查哪些证据，才能说它确实从经验中改善了后续行为？

提示

把“写进去了”与“下次用到了且有帮助”分开。

参考思路

至少比较保留记忆、清空记忆和相同容量的无效记忆对照；检查新信息是否改变后来决策，以及改进能否跨经历持续。仅有 hidden state 变化或一次搜索成功不够。是否称为学习，还要说明采用的定义与 agent 边界。

读完留下：一张四列表：更新对象／更新时刻／保留多久／怎样影响未来行为。
